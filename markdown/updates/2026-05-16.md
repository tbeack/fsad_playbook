# 2026-05-16 — Claude Code v2.1.143

## New Features
- Added plugin dependency enforcement: `claude plugin disable` now refuses when another enabled plugin depends on the target (with copy-pasteable disable-chain hint); `claude plugin enable` force-enables transitive dependencies → **Affects:** No playbook impact (behavioral, no dedicated table for plugin dependency graphs)
- Added projected context cost (per-turn and per-invocation token estimates) to the `/plugin` marketplace browse pane → **Affects:** No playbook impact (UI detail in marketplace pane, no config or command change)
- Added `worktree.bgIsolation: "none"` setting to let background sessions edit the working copy directly without `EnterWorktree` → **Affects:** Power Usage → Work Trees (new setting, needs documentation)
- PowerShell tool now passes `-ExecutionPolicy Bypass` by default; opt out with `CLAUDE_CODE_POWERSHELL_RESPECT_EXECUTION_POLICY=1` → **Affects:** Subprocess Sandboxing hardening env vars table (new opt-out env var)
- Background sessions now preserve the model and effort level you set after waking from idle → **Affects:** No playbook impact (behavioral fix, no config change)
- Shift+Tab in attached agent sessions now includes auto mode in the cycle → **Affects:** No playbook impact (minor UI change)
- The PowerShell tool is now enabled by default on Windows for Bedrock, Vertex, and Foundry users; opt out with `CLAUDE_CODE_USE_POWERSHELL_TOOL=0` → **Affects:** Subprocess Sandboxing hardening env vars table (new opt-out env var)
- `claude agents` now accepts `--add-dir`, `--settings`, `--mcp-config`, `--plugin-dir` and `--permission-mode`, `--model`, `--effort`, `--dangerously-skip-permissions` → **Affects:** Already documented (CBP-147)

## Fixed
- Fixed stop hooks that block repeatedly looping forever — the turn now ends with a warning after 8 consecutive blocks (override via `CLAUDE_CODE_STOP_HOOK_BLOCK_CAP`) → **Affects:** Subprocess Sandboxing hardening env vars table (new env var documenting the cap)
- Fixed Esc/Ctrl+C not cancelling a pending `/loop` wakeup → **Affects:** No playbook impact
- Fixed `/goal` evaluator firing while background shells or delegated subagents are still running → **Affects:** No playbook impact
- Fixed `NO_COLOR`/`FORCE_COLOR` in settings.json `env` stripping Claude Code's own UI colors → **Affects:** No playbook impact
- Multiple Windows, worktree, plugin, and agent-view fixes → **Affects:** No playbook impact
