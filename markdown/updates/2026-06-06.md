# 2026-06-06 — Claude Code v2.1.167

## New Features
- Added `fallbackModel` setting to configure up to three fallback models tried in order when the primary model is overloaded or unavailable; `--fallback-model` now also applies to interactive sessions → **Affects:** Cheat Sheet (CLI flags table), Notable settings.json Keys callout
- Added glob pattern support in deny rule tool-name position (`"*"` denies all tools); allow rules reject non-MCP globs; unknown tool names in deny rules warn at startup → **Affects:** Config Cascade / permissions section

## Changed
- `MAX_THINKING_TOKENS=0`, `--thinking disabled`, and the per-model thinking toggle now disable thinking on models that think by default via the Claude API (3P providers unchanged) → **Affects:** No playbook impact (internal behavior change, thinking controls already documented in Effort Levels)
- Claude Code now retries a turn once on the fallback model when the API rejects an unexpected non-retryable error → **Affects:** No playbook impact (internal reliability behavior)
- `claude update` now announces the target version before downloading instead of going silent → **Affects:** No playbook impact (UX improvement only)
- `claude agents`: typing a URL into the list now filters to the session whose first prompt contained it → **Affects:** No playbook impact (UX improvement only)
- Hardened cross-session messaging: `SendMessage` from other Claude sessions no longer carries user authority → **Affects:** No playbook impact (internal security hardening)

## Fixed
- Fixed a recurring "image could not be processed" error and extra token usage → **Affects:** No playbook impact
- Fixed remote sessions becoming permanently stuck on backend disruption → **Affects:** No playbook impact
- Fixed flickering in JetBrains IDE terminals on 2026.1+ → **Affects:** No playbook impact
- Fixed Shift+non-ASCII characters being dropped in Kitty keyboard protocol terminals → **Affects:** No playbook impact
- Fixed PowerShell command validation hanging on Windows → **Affects:** No playbook impact
