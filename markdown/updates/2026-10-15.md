# 2026-10-15 — Claude Code v2.1.300

## New Features
- Added `virtualText` to a mod's prompt decorations: text drawn in the prompt box that never enters the draft or the submitted prompt → **Affects:** Mods section (Building Skills page / Practices)
- Added `$.ui.view({ agentId })` for mods: shows an agent's transcript in the main view; `$.ui.view({})` goes back → **Affects:** Mods section mods API note
- Added the `prompt.change` mod hook, raised when the prompt box's text changes without a typed edit (recalled history, clear, undo, plugin fill) → **Affects:** Mods section (new event to document)
- Added `/advisor` on Claude Platform on AWS; no advisor runs until you pick one; `CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1` turns it off → **Affects:** Cheat Sheet `/advisor` row
- Added `cache_creation_5m_tokens` and `cache_creation_1h_tokens` to the OpenTelemetry `api_request` event, splitting cache writes by lifetime → **Affects:** Monitoring events table `claude_code.api_request` row
- Added OpenTelemetry GenAI semantic-convention attributes to trace spans (`gen_ai.provider.name`, `gen_ai.conversation.id`, `gen_ai.tool.name`, `error.type`) → **Affects:** Monitoring section (new span attributes)
- Added support for rewriting a workflow agent's `prompt` and `model` in the `agent.spawn` mod hook → **Affects:** Mods section mods API note

## Changed
- Changed `/sandbox` mode option labels: "Sandbox commands" replaces "Sandbox BashTool" → **Affects:** `/sandbox` cheat sheet row (minor label update)
- Changed large requests to `api.anthropic.com` to use gzip compression even when telemetry is disabled → **Affects:** No playbook impact
- Changed `CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST` sessions to ignore CA-bundle and tool-proxy variables in settings → **Affects:** No playbook impact (enterprise-managed only)

## Fixed
