# 2026-10-02 — Claude Code v2.1.287 + Codex rust-v0.160.0

## Claude Code v2.1.287 (new since v2.1.286)

### New Features
- Added Claude Mods: plugins may now modify deeper behavior → **Affects:** Claude Best Practices (Plugins section)
- Added "You Should Know" built-in mod (`/plugin enable cc-plugin-you-should-know@builtin`): a side agent that watches your back and flags things you or Claude might miss → **Affects:** Claude Best Practices (Plugins section)
- Added `n:<text>` filter to agents view: matches session names and tasks; collapsed sections show matches; Enter opens first match → **Affects:** Claude Best Practices (Session & Resume cheat sheet)
- Added `prompt_text` to OpenTelemetry `user_prompt` event (copy of `prompt` for dotted-key backends) → **Affects:** No playbook impact
- Added URL prompts from MCP servers on 2025-11-25 protocol; add `"bareElicitationCapability": true` to MCP config entry if a server stops connecting after this update → **Affects:** Claude Best Practices (Plugins / MCP section)
- Self-hosted runner: added built-in `gh api` (REST only) for Anthropic-managed git sessions where GitHub CLI is not installed → **Affects:** No playbook impact (too niche/enterprise)
- Windows: added startup warning when denying Bash also turns off PowerShell → **Affects:** No playbook impact

### Fixed
