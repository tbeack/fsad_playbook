# 2026-10-21 — Claude Code v2.1.305 (and v2.1.306)

## New Features
- `sandbox.allowNestedUserNamespaces` — lets sandboxed commands on Linux create user namespaces (needed for Chromium, rootless podman); explicitly gets around the sandbox's file protections. → **Affects:** CBP-705
- `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` — unattended retry mode (`CLAUDE_CODE_RETRY_WATCHDOG`) rechecks whether a usage limit was lifted before its scheduled reset. → **Affects:** CBP-706

## Changed
- `allowedMcpServers` no longer filters out `managed-mcp.json` stdio servers that use `${VAR}` only in `env` — a server previously left out by your allowlist now loads on upgrade; `deniedMcpServers` is the way to keep it off. Config-filtering edge case, not covered by the playbook's MCP settings rows at this level of detail. → **Affects:** No playbook impact
- `/artifacts` delete confirmation keys changed (`1`/Enter to keep, `2` to delete, `Esc` to cancel; `y`/`n` no longer answer it) — UI micro-interaction, not documented in the playbook. → **Affects:** No playbook impact
- Plugins Claude Desktop mounts by path no longer keep `allowed-tools` under `allowManagedPermissionRulesOnly` — enterprise-managed-settings edge case outside the playbook's scope. → **Affects:** No playbook impact

## Fixed
- A 2.1.304 regression breaking every request on Vertex, Bedrock, and other providers/gateways with tool search disallowed (v2.1.305 reverts it) — regression fix, no playbook anchor describing the broken state to correct.
- `/effort`/`/autocompact` settings not applying when the model name differs from a `modelOverrides` value by case or a `[1m]` tag — bug fix.
- Worktree, Bash-on-full-disk, MCP-server-override, subagent-model-naming, compaction-notice, WebFetch-approval-wait, Workflow-resume, `/resume` empty-entry, `/usage` narrow-terminal, startup-warning, and screen-reader fixes — internal reliability/UX fixes, no user-facing workflow change worth documenting.
- Self-hosted runner, VS Code, Cloud sessions, Claude Tag, and Code Review fixes — internal, no playbook impact.
- (v2.1.306) `claude -p` inside cloud sessions wrongly reporting "Not logged in"; an API error being masked by "prompt is too long" with an unneeded compaction in sessions with many MCP tools — both bug fixes, no playbook impact.
