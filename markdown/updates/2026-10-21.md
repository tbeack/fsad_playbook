# 2026-10-21 — Claude Code v2.1.306

## New Features
- `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` — sets how often the retry watchdog rechecks whether a usage limit lifted before its reset time, so unattended sessions can resume sooner (v2.1.305). → **Affects:** CBP-705
- `sandbox.allowNestedUserNamespaces` — lets sandboxed commands on Linux create user namespaces, which Chromium and rootless podman need (v2.1.305). → **Affects:** CBP-706
- `CLAUDE_CODE_AUTO_COMPACT_WINDOW` — env var to set a custom auto-compact token window; now accepts `k` and `M` suffixes (e.g. `200k`, `1M`) and warns when the value is out of range or ignored (v2.1.305). → **Affects:** CBP-709

## Changed
- `/usage` improvements — each warning is now a one-line fix naming its source; press `f` to apply all fixes. The same fixes appear in VS Code and `/doctor` (v2.1.305). → **Affects:** CBP-707
- `allowedMcpServers` behavior for `managed-mcp.json` — stdio servers in `managed-mcp.json` that use `${VAR}` only in their `env` field are no longer filtered out by `allowedMcpServers`; one omitted from your allowlist now loads on upgrade. Use `deniedMcpServers` to keep it off (v2.1.305). → **Affects:** CBP-708
- `/artifacts` delete confirmation now uses numbered choices (1 or Enter = keep, 2 = delete, Esc = cancel); `y` and `n` no longer work (v2.1.305). → **Affects:** No playbook impact (`/artifacts` is not in the cheat sheet)
- `allowedMcpServers` for path-mounted plugins with `allowManagedPermissionRulesOnly` — managed setting now strips `allowed-tools` from plugins Claude Desktop mounts by path (v2.1.305). → **Affects:** No playbook impact (internal managed-settings behavior)

## Fixed
- v2.1.305: Extensive reliability, VS Code, Remote Control, Claude Tag, MCP, sandbox, and worktree fixes — internal, no user-facing workflow change worth documenting. → **Affects:** No playbook impact
- v2.1.306: Fixed `claude -p` inside cloud sessions reporting "Not logged in" — bug fix. → **Affects:** No playbook impact
- v2.1.306: Fixed API error replaced by "prompt is too long" and unneeded compaction with many MCP tools — bug fix. → **Affects:** No playbook impact
