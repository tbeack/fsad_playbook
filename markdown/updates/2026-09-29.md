## Claude Code v2.1.284

### New Features

- Added Claude Sonnet 5.5 (`claude-sonnet-5-5`), now the default Sonnet model on the Anthropic API — 1M context, $2/$10 per Mtok, $0.20/Mtok cache reads → **Affects:** Current model lineup table (new column), `sonnet` alias row, `default` alias row, Key Dates callout
- Changed interactive terminal and VS Code sessions to start in **auto mode** when no permission mode is configured, on every plan and provider (`permissions.defaultMode` still overrides it) — extends the Bedrock/Vertex/Foundry-only auto-mode default from v2.1.207 to every surface → **Affects:** Permission Modes section
- Changed Ultracode into its own toggle in `/effort` (Tab, or `/effort ultracode [on|off]`): no longer forces `xhigh` effort and stays on at any effort level → **Affects:** Dynamic Workflows → Trigger keyword `ultracode` callout
- Added `/mcp reconnect all` to retry every MCP server that failed to connect or needs authentication at once → **Affects:** `/mcp` Cheat Sheet row
- Added a "Yes, but ask again next time" answer to auto mode's prompt before a read outside the working directories, so you can allow that one read and still be asked about later ones → **Affects:** `permissions.blockReadsOutsideWorkingDirectories` Notable Settings bullet
- Added `/rate-limit-options` to `/help` and the command menu for claude.ai subscribers, dollar amounts in the Claude apps gateway spend limit (`/usage`/status line), `effortSlider` keybinding actions, gateway startup warnings for empty/incomplete `availableModels`, `auth: { google: {} }` gateway telemetry destination, certificate client auth (`private_key_jwt`) for the gateway's identity provider → No playbook impact (enterprise gateway/telemetry internals and a usage-limit command outside current doc scope)
