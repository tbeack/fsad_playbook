# 2026-09-19 — Claude Code v2.1.278 + Codex rust-v0.155.1

## Claude Code v2.1.278 (new, was v2.1.276)

### New Features

- **Auto mode server-side classifier now default** — For Claude API and Enterprise users, and on Bedrock, Vertex, Foundry, and gateways, auto mode now defaults to the server-side classifier (no billing for classifier overhead). `CLAUDE_CODE_AUTO_MODE_SERVER=0` opts out on Bedrock, Vertex, Foundry, and gateways. Warns when a billed fallback occurs. See [auto-mode-classifier-billing](https://code.claude.com/docs/en/auto-mode-classifier-billing). → **Affects:** Notable Environment Variables table (env var row must be rewritten) and Cheat Sheet `/status` row (v2.1.278)

- **`/status` "Auto mode server" row** — `/status` now shows an "Auto mode server" row indicating whether the current session's auto mode classifier runs on the server. → **Affects:** Cheat Sheet `/status` row (v2.1.278)

### Changed (v2.1.277)

- **AGENTS.md fallback for Claude Code** — In a project with no CLAUDE.md, Claude Code now reads AGENTS.md instead. Change it under "Project instructions" in `/config`. Not yet available on Bedrock, Vertex, or Foundry. → **Affects:** Project Anatomy / CLAUDE.md section — "Codex Equivalent" callout and/or project instructions description (v2.1.277)

- **`CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1`** — New env var for Claude apps gateways whose only egress is a forward proxy. Every outbound request passes the proxy the hostname instead of resolving it locally. → **Affects:** Notable Environment Variables table (v2.1.277)

- **`headers:` map on Claude apps gateway upstreams** — Optional static headers can now be sent to a proxy running in front of a provider. Niche gateway-admin config. → **Affects:** No clear playbook section (gateway admin docs, not deferred)

- **Background task update notification** — A line now appears when a background task finishes while a panel like `/tasks` is open, indicating an update is waiting. → **Affects:** No playbook impact (UX micro-detail)

### Fixed (v2.1.277) — No playbook impact

- `claude -p` and Agent SDK sessions no longer hang with no result after an internal error.
- Conversations no longer fail with "text content blocks must be non-empty" from empty assistant turns.
- Unexpected logout fix when an older Claude Code build runs on the same machine.
- Interactive start-up hang fix for `ANTHROPIC_API_KEY` users with malformed `customApiKeyResponses`.
- Update checks no longer error every 30 minutes when a proxy returns an invalid version.
- `claude update` on winget- or apk-managed installs no longer reports "up to date" on failed version lookup.
- `claude plugin install` no longer fails reinstalling a version another session holds.
- Grep and Glob now return an error instead of reporting no matches when system is out of processes/memory/file handles.
- Write tool now reports a clear error when target path is an existing directory.
- Edit tool no longer misinterprets escaped backslash + `uXXXX` as a `\uXXXX` escape.
- Edit tool now reports "String not found in file" instead of "Invalid regular expression" on very large edits.
