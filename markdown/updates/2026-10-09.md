# 2026-10-09 — Claude Code v2.1.295 + Codex rust-v0.162.0

## New Features (Claude Code v2.1.295)

- Added `onFailure: "block"` for command and HTTP hooks: a hook that can't start, times out, or exits with an unexpected code now blocks the action instead of letting it through. **Affects:** Hooks section (practices page)
- Added `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS` env var: limits how long unattended retry mode waits out 429/529 errors. **Affects:** Env vars table (practices page)
- Added `$.ui.notify` for mods: raises a native notification through the user's notification setting, tagged by the channel that sent it. **Affects:** Mods section (practices page)
- Added `upstream_request_id` to gateway audit events. **Affects:** No playbook impact
- Added children to a mod's `Button` — strings and `Text`, enabling pressable rows with chips or dim details. **Affects:** No playbook impact (implementation detail)
- Added Program Status Protocol (OSC 7501) — terminals can show Claude's working/idle status. **Affects:** No playbook impact
- Added optional `models` list for Claude apps gateway upstreams. **Affects:** No playbook impact (enterprise config)
- Added `forceLoginMethod: "gateway"` + `forceLoginGatewayUrl` in user settings. **Affects:** No playbook impact (enterprise config)

## Changed (Claude Code v2.1.295)

- MCP tool descriptions loaded via tool search cut at 16,384 characters (was 2,048). **Affects:** No playbook impact (automatic)
- Subagents preload at most 32 skills from the `skills` field. **Affects:** No playbook impact (limit already existed)
- Grep tool now accepts `-l`, `-c`, `-r` flags without failing. **Affects:** No playbook impact (bug fix)
