# 2026-10-09 — Claude Code v2.1.295 / Codex CLI rust-v0.162.0

## Claude Code Changes (v2.1.294 - v2.1.295)

### New Features
- `onFailure: "block"` for command and HTTP hooks: a hook that cannot start, times out, or exits with an unexpected code now blocks the action instead of letting it through. **Affects:** Hooks Deep Dive section (fail-open default note, hook examples)
- `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS`: limits how long unattended retry mode waits out 429 and 529 errors. **Affects:** Env vars table (new row after RETRY_WATCHDOG)
- `$.ui.notify` for mods: raises a native notification through the user's notification setting. **Affects:** Mods section (deferred — mods API not covered deeply)
- `forceLoginMethod: "gateway"` and `forceLoginGatewayUrl` in user settings. **Affects:** No playbook impact — gateway admin config
- `upstream_request_id` in audit events and `timeouts.upstream_ttfb_ms` for gateway upstreams. **Affects:** No playbook impact — gateway internals

### Changed
- MCP tool descriptions loaded through tool search are now cut at 16,384 characters (was 2,048). **Affects:** `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` env var row (update cap note)
- Subagents preload at most 32 skills from the `skills` field. **Affects:** Multi-agent section (deferred — needs verification of current text)
- MCP server `models` list for gateway upstreams. **Affects:** No playbook impact — gateway config

### Fixed
- Many fixes (hooks, MCP, plugin, VS Code, Bash permission checks, etc.) — **No playbook impact**
