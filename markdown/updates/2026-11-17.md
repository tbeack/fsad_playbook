## Claude Code v2.1.326

### New Features / Behavior Changes

- Added support for turning on Code Mode while agent teams are enabled; if you already turned it on, sessions with teams on now start in Code Mode. → **Affects:** Claude Best Practices — Code Mode collapsible (Update existing)
- Added a row to `/status` that says when your provider or an environment variable such as `DISABLE_TELEMETRY` turns features off. → **Affects:** Claude Best Practices — `/status` row (Update existing)
- Added Ctrl+O to show hidden startup notices. → **Affects:** Claude Best Practices — `Ctrl+O` keyboard shortcut row (Update existing)
- Added a note in `/plugin` and `claude plugin list` when a malformed `plugin.json` field such as `author` or `homepage` is ignored. → **Affects:** Claude Best Practices — Plugins section, `plugin.json` warnings list (Update existing)
- Reviewed and deferred as no/low playbook impact at this scope: the startup warning for malformed `--allowedTools`/`--disallowedTools`/`--tools` entries, the `managed-mcp.json` loading-stopped explanation message, the empty-prompt failure hint, the `esc to stop` subagent-view footer hint, `OTEL_RESOURCE_INCLUDE_HOST`, the mod `Box`/`Text` layout props (`overflowX`, `maxLines`, `wrap`), and the large volume of other bug fixes (settings-file handling, sandboxed command startup, background-service process matching, resumed-session history, hook/OTEL edge cases, etc.) reviewed this cycle — none rose to playbook-documentation relevance at this scope.
