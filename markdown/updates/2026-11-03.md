# 2026-11-03 — Claude Code v2.1.317

## Claude Code v2.1.317 (new since v2.1.316)

### Added
- Added a warning to `/schedule` when a new cloud scheduled task gets connectors you did not ask for, with how to remove them → **Affects:** Practices page (`/schedule` cheat-sheet row)
- Added a check that asks before a web or shell tool call sends your account email address to the network → **Affects:** Practices page (Privacy & Security list, next to the existing OAuth-email bullet)
- Added `onFailure: "block"` for Agent SDK hook callbacks, so a callback that fails blocks the action instead of letting it run → **Affects:** No playbook impact (playbook's existing `onFailure: "block"` documentation (v2.1.295) covers Claude Code CLI hooks; the playbook does not document Agent SDK hook-callback APIs at this level of detail)
- Added a notice in Claude Desktop's Code tab when org remote managed settings haven't loaded for the session, and another once they do → **Affects:** No playbook impact (desktop UI notice, not a configurable behavior)
- Added a notice when auto mode's check has no answer for a subagent's tool call → **Affects:** No playbook impact (narrow UI notice)
- Added `anthropic.plan`, `anthropic.seat_type`, `anthropic.provider` and `anthropic.custom_base_url` to OTel metrics, events and spans → **Affects:** Practices page (Monitoring → Metrics collapsible)
- Added a cost report to the Claude apps gateway admin API (`GET /v1/organizations/analytics/cost`) → **Affects:** No playbook impact (enterprise gateway admin API, consistent with past admin-API items)
- Added a daily IdP-group record on Claude apps gateways, kept for `admin.identity_retention_days` → **Affects:** No playbook impact (enterprise gateway admin feature)
- Added `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID` → **Affects:** Practices page (env var table, self-hosted-runner adjacent)

### Changed
- Changed subagents and teammates on a different model from the main conversation to use that model's saved effort level or its default, instead of the session's effort level → **Affects:** Practices page (Cost Optimization Checklist's Agent-tool-effort bullet)
- Changed SendMessage so a message to a running background agent arrives earlier → **Affects:** No playbook impact (internal messaging timing, not a documented behavior)
- Changed exit to skip the "Background work is running" prompt for plugin monitors → **Affects:** No playbook impact (narrow plugin-monitor UX)
- Changed the built-in `plugin-authoring` skill to offer once, after a mod works, to help share it → **Affects:** No playbook impact (Anthropic's own built-in skill behavior, not something this playbook documents)

### Removed
- Removed the Read tool's "file unchanged since your last Read" stub: reading an unchanged file again returns its content → **Affects:** No playbook impact (this stub behavior was never documented in the playbook, so there's nothing to amend)

### Fixed / Improved
