# 2026-05-12 — Claude Code v2.1.139

## New Features
- Added agent view (Research Preview): `claude agents` CLI command shows a unified list of every Claude Code session — running, blocked, or done → **Affects:** Cheat Sheet (CLI subcommands)
- Added `/goal` command: set a completion condition and Claude works across turns until met. Live elapsed/turns/tokens overlay panel → **Affects:** Cheat Sheet (session management / automation table) — already in Codex section but NEW for Claude
- Added `/scroll-speed` command to tune mouse wheel scroll speed with a live preview → **Affects:** Cheat Sheet (configuration table)
- Added `claude plugin details <name>` to show a plugin's component inventory and projected per-session token cost → **Affects:** Plugins collapsible (minor, no task)
- Added transcript view navigation: `?` for keyboard shortcuts, `{`/`}` to jump between user prompts, `v` to toggle shortcut panel → **Affects:** No playbook impact (UI navigation)
- Added hook `args: string[]` field (exec form) that spawns command directly without a shell — path placeholders never need quoting → **Affects:** Hooks Deep Dive section
- Added hook `continueOnBlock` config option for `PostToolUse` — set to `true` to feed hook's rejection reason back to Claude and continue the turn → **Affects:** Hooks Deep Dive section
