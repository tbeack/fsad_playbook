## Claude Code Changes (v2.1.234)

### New Features
- **`CLAUDE_CODE_PROJECT_DIR_NAME`** (optional env var) — hosts that give each session its own config directory can choose a short name for the per-project transcript directory. → **CBP-380**
- **`selection:clear` keybinding action** — a key can be bound to clear an in-app text selection; also works in the agents view. → **CBP-381**
- **GitLab merge request badge in footer + statusline** — repos with a GitLab remote and an authenticated `glab` CLI show `MR !N` with draft/pending/green states. → **CBP-382**
- **Auto-continue at usage limit** — Claude Code now continues your session automatically when a claude.ai usage limit resets; turn it off in `/config` ("Continue automatically at usage limit"). → **CBP-383**

### Changed
- `SendMessage` / `ListAgents` now say when your account's session list was too long to check completely, instead of treating unseen sessions as absent. → **CBP-384**
- Remote Control: effort picks made on a phone or on claude.ai/code now apply to terminal- and Desktop/VS Code-hosted sessions, and the session publishes its effort level to connected clients. → **CBP-385**
- Remote Control sessions started from Claude Code Desktop or VS Code now keep phones and claude.ai/code updated on the session's permission mode (and claude.ai/code on the model) as they change. → **CBP-385**
- Remote Control: signing this computer in to a different claude.ai account or organization now stops the running session within seconds and says why, instead of a misleading HTTP 404 hours later. → **CBP-385**
- Claude is now told to use your account email only to identify you, and not to send it to unrelated services unless you ask. → **no action** — model-behavior/privacy guidance with no configurable surface and no matching table or callout anywhere in the playbook (verified across all Claude anchor groups in the Phase 3 sweep).
- Expired Anthropic profile credential now points you at `/login` when a claude.ai login would take precedence. → **no action** — too narrow to justify expanding the one-line `/login` Cheat Sheet row; no behavior change users need to plan around.
- Improved the transcript: your own prompts now render markdown (highlighted code blocks, inline code, lists) the same way replies do. → **no action** — cosmetic TUI rendering; the playbook documents transcript *files* and the `Ctrl+O` toggle, not transcript styling.

### Fixed
- Security: remote file reads, session restore, CLAUDE.md includes, workflow scripts and file uploads now reject Windows NT-namespace (`\??\`) paths, hardening the remaining pre-approval file accesses against the NTLM credential-leak vector. → **no action** — internal hardening with no user-facing setting to configure; the playbook has no path-normalization or CVE-tracking surface.
- The remaining ~22 fixes are internal bug fixes with no documented behavior or setting change: auto-mode network re-checks after compaction; dropped session-scoped permission answers for background subagents; crash on malformed thinking/text blocks via third-party gateways; slow markdown rendering on unusual Unicode; `SendMessage` rejecting 200-char/emoji-heavy recipient names; repo host mis-detection on unusual git remote userinfo; MCP diagnostics printing resolved secrets; `strictKnownMarketplaces` accepting SCP-style git sources; fullscreen modal text losing characters on copy; `---` horizontal rule collision; shell-command row splitting; dialogs dismissed by finishing `!` commands; queued `!` command sent as plain text; queued-message history and Esc handling; fullscreen-renderer prompt losing permission mode/flags on restart; `/tui` dropping `--allowed-tools`/`--disallowed-tools`; trust prompts omitting repo-wide scope warning; IDE diff tab closing answering the wrong permission prompt; Remote Control file uploads showing empty cards; `CLAUDE_CODE_OAUTH_TOKEN` stale-token reminder leaking into the resumed turn; permission-preview relay trust gating and capability opt-out; credential masking hiding commands/paths from the approver; provider token masking before shell delimiters; Claude Desktop inter-session messages silently dropped. → **no action** (all).
