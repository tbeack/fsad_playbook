# 2026-07-16 (Update 2) — Claude Code v2.1.212

## New Features

- `/fork` now copies the current conversation into a new background session (own row in `claude agents`) while you keep working in the original; the in-session subagent it used to launch is now `/subtask` → **Affects:** Cheat Sheet — Automation & agents table (new rows)
- Added `claude auto-mode reset` CLI subcommand to restore default auto-mode configuration; pass `--yes` to skip confirmation → **Affects:** Cheat Sheet — Info & account table (new row)
- Added per-session cap on WebSearch tool calls (default 200, env var `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION`) → **Affects:** Subprocess Sandboxing hardening env vars table (new row)
- Added per-session cap on subagent spawns (default 200, env var `CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`); `/clear` resets the budget → **Affects:** Subprocess Sandboxing hardening env vars table (new row)
- MCP tool calls running >2 minutes now move to background automatically; configure threshold or disable with `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS` → **Affects:** Subprocess Sandboxing hardening env vars table (new row)
- `/resume` in agent view now opens a picker including sessions deleted from the list, and resumes pick as background session → **Affects:** Cheat Sheet — Session management /resume row (update)

## Changed

- Deprecated `Task tool's mode` parameter — subagents now inherit parent session's permission mode → **Affects:** No playbook impact (internal deprecation)
- `forceLoginMethod` now enforced for VS Code extension and SDK logins too → **Affects:** No playbook impact (Enterprise config)

## Fixed (notable)

- Plan mode no longer auto-runs file-modifying Bash commands without permission prompt → **Affects:** No playbook impact (bug fix)
- OpenTelemetry HTTP exports fixed for Azure Monitor (chunked transfer encoding) → **Affects:** No playbook impact (bug fix)
- Web search/fetch reliability improved with 529/rate-limit backoff → **Affects:** No playbook impact (bug fix)
