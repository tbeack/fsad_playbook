# 2026-11-21 — Claude Code v2.1.330

Claude Code v2.1.330 is new (up from v2.1.329). Fetched via the npm `@anthropic-ai/claude-code` registry and the GitHub-hosted `CHANGELOG.md`. (This run's scope was Claude Code only — Codex CLI wasn't checked.)

## Claude Code v2.1.330

### New Features / Behavior Changes

- Added `easel`, a built-in mod that draws charts when asked and under MCP metrics results, on Pro, Max, and — where available — Team and Enterprise, on macOS and Linux; turn off automatic charts in `/config`. → **Affects:** Claude Best Practices — Built-in Mods table (Add new row)
- Changed recurring scheduled tasks and `/loop` to run up to 30 days instead of 7 while their session keeps running, and say when they end; tasks made before this release still end at 7 days. → **Affects:** Claude Best Practices — `/schedule` row + Loop collapsible callout (Update existing)
- Changed more `rm` commands aimed at the root, home, a top-level folder, or the working folder to ask for approval; where nobody can answer, they're refused. → **Affects:** Claude Best Practices — Subprocess Sandboxing paragraph (Update existing)
- Changed a subagent's model fallback to carry over: agents with no model and forks it then starts run on the fallback, and the agents they start use its Bedrock region. → **Affects:** Claude Best Practices — `fallbackModel` bullet (Update existing)
- Changed skills that Claude runs with a `model` setting, other than `context: fork` skills, to leave subagents, forks, compaction, and `/recap` on the session's model. → **Affects:** Claude Best Practices — skill `model` frontmatter row (Update existing)
- Improved the claude.ai sign-in link shown by `/login`, `claude auth login`, and `claude setup-token`: it is now much shorter; added `CLAUDE_CODE_FULL_SIGN_IN_LINK=1` to print the full link instead. → **Affects:** Claude Best Practices — `/login` row (Update existing)
- Reviewed and deferred as no/low playbook impact at this scope: the Enterprise Admin Console sign-in flow (org-managed cloud provider/gateway selection, no CLI-usage change for the teams this playbook targets), the self-hosted runner `--start-dir` flag and its metrics/registration additions, `claude plugin install --json`'s new `commandPrinted`/`commandFailed` fields, the Code Mode / terminal-freeze / WebFetch-freeze / worktree-exit / settings-race / `--resume` / `/rewind` / Grep-multiline / Jupyter-BOM and the large volume of other bug fixes, VS Code–specific fixes, and self-hosted-runner reliability fixes reviewed this cycle (none rose to playbook-documentation relevance at this scope).
