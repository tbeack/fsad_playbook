## Claude Code v2.1.316 (new since v2.1.314)

### New Features
- Added `CLAUDE_CODE_DISABLE_ULTRATHINK`, which turns the `ultrathink` keyword off → **Affects:** Practices page (ultrathink keyword example + env var table)
- Added pooled group budgets to the Claude apps gateway: one monthly budget a group's members share, set with `pooled_budget` on the spend limits admin API → **Affects:** No playbook impact (enterprise gateway admin feature)
- Added `CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP` to keep looped system cross-certificates for servers whose private CA needs one → **Affects:** No playbook impact (narrow enterprise TLS edge case)
- Added `CLAUDE_CODE_SUBAGENT_EFFORT` to set the effort level subagents run at when nothing else names one → **Affects:** Practices page (Cost Optimization Checklist + env var table)
- Added `managed.policy_mode: layered` to the Claude apps gateway → **Affects:** No playbook impact (enterprise gateway admin feature)
- Added `guardrail.input_tagging` on Claude apps gateway Bedrock upstreams → **Affects:** No playbook impact (enterprise gateway admin feature)

- Server-managed settings for Team/Enterprise logins now apply without an approval prompt → **Affects:** No playbook impact (admin-side behavior change)
- [VSCode] `ultrathink` now runs at `xhigh` effort and shows the rainbow highlight in VS Code, matching the terminal → **Affects:** No playbook impact (closes a VS Code parity gap; the playbook's existing `ultrathink` docs already describe the terminal behavior and don't call out a VS Code lag)
