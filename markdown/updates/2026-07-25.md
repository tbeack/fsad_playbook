# 2026-07-25 — Claude Code v2.1.220

## Summary
Claude Code has two new versions since the last check (v2.1.218 → v2.1.220). Codex is unchanged at rust-v0.145.0.

- **v2.1.220**: Bug fixes and reliability improvements (no specific playbook impact)
- **v2.1.219**: Several notable features with playbook impact (detailed below)

---

## v2.1.219 New Features

- Added Claude Opus 5 (`claude-opus-5`), now the default Opus model — 1M context, fast mode at $10/$50 per Mtok → **Affects: Model Selection table, `opus` alias row, Key Dates callout**
- Added `sandbox.network.strictAllowlist` setting to deny non-allowlisted hosts for sandboxed commands without prompting → **Affects: Sandbox settings table**
- Added `DirectoryAdded` hook that fires after `/add-dir` or the SDK `register_repo_root` control request registers a new working directory mid-session → **Affects: Environment & context hooks table**
- Added the `workflowSizeGuideline` settings key so the advisory Dynamic workflow size guideline can be set from any settings file → **Affects: Notable settings.json Keys callout**
- Added nested subagent forwarding in stream-json: subagents spawned at depth-2+ now appear when `--forward-subagent-text` is set, keyed by their spawning Agent `tool_use` id → **Affects: Print/programmatic mode CLI flags table**

## v2.1.219 Fixed / Changed

- Fixed `claude -p` text output dropping already-produced answer on mid-stream API error → **No playbook impact**
- Added HTTP status and error text to `claude mcp list` and `/mcp` on server connection failure → **No playbook impact**
- Fixed Fable model "Requires usage credits" label showing incorrectly → **No playbook impact**
- Fixed `/model` picker showing merged Opus row as plain "Opus" instead of "Opus (1M context)" → **No playbook impact**
- Fixed copy-on-select inside GNU screen printing base64 → **No playbook impact**
- Fixed Remote Control clients keeping stale fast-mode status after model switch → **No playbook impact**
- Fixed `CLAUDE_CODE_GIT_BASH_PATH` on Windows → **No playbook impact**
- Fixed Vim mode ← on empty prompt returning to agent view from NORMAL mode → **No playbook impact**
