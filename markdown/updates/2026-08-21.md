# 2026-08-21 — Claude Code v2.1.238 / Codex CLI v0.149.0

## Claude Code Changes

### New Features
- Added a `keybindingFlavor` setting: set to `"readline"` to make Ctrl+W in the prompt delete back to the previous whitespace, as in Bash; default (`"classic"`) unchanged
- Plugin marketplaces: `headersHelper` on a url marketplace or catalog entry runs a command that mints HTTP headers (e.g. a short-lived token) for catalog and same-origin archive fetches; runs only on install/update, with `[y/N]` confirmation (or `-y`)
- Added `claude self-hosted-runner --defer-shutdown-max-min <minutes>`: on SIGTERM, keep serving attached sessions, park what is left after that many minutes, then exit
- Added `claude self-hosted-runner --proxy-authorization-command` / `--proxy-authorization-file` for egress proxies requiring a freshly issued `Proxy-Authorization` header on every connection

### Changed
- Ctrl+L and Cmd+K in fullscreen now always just repaint — the double-press `/clear` shortcut was removed, and 1-row nvim terminals no longer trigger automatic `/clear` loops
- `claude mcp list` and `claude mcp get` now show disabled servers as `⊘ Disabled` instead of connecting to them for a health check
- MCP `headersHelper` in a project `.mcp.json`, and inline MCP servers in project or `--add-dir` agent files, now require that folder's trust dialog to have been accepted (also under `claude -p`)
- MCP `headersHelper` from a project `.mcp.json`, plugin, or agent file runs without inherited credential env vars; user/managed/claude.ai-scope helpers now run from the Claude config dir
- Updated the bundled `claude-api` skill for the Managed Agents Aug 19 release (web search/fetch domain settings, memory stores on self-hosted sandboxes)
- Improved startup: bare `claude` starts sooner on macOS; automatic update check now runs ~10s after launch instead of competing with startup for CPU
- Improved Remote Control connection resilience: brief HTTP 403 refusals tolerated up to 3 minutes, with the refusing party named when a block persists
- Improved Bash tool permission checking for zsh-specific syntax in shell conditionals

### Fixed
- Fixed unbounded memory growth in long interactive sessions (subagent tool results released once outside the recent display window)
- Fixed custom/project/plugin output styles drifting back to the default voice mid-session
- Fixed `CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=true` not keeping prompt suggestions on near (but not over) usage limit
- Fixed worktree-isolation Bash refusals telling you to remove a redirect when the command had none
- Fixed self-hosted runners occasionally being removed by the server after a single slow/lost poll request
- Fixed MCP elicitation dialogs showing nothing for URLs longer than 4,096 characters; fixed permission prompts dropping "don't ask again" when the project path didn't fit terminal width
- Fixed leftover `/tmp/claude-*-cwd` files on killed/timed-out/interrupted Bash commands
- Fixed held Backspace being ignored on terminals sending Ctrl+H in large keystroke bursts
- Fixed text-wrapping in permission prompt diffs for wide multi-code-point characters/tabs
- Fixed killing a suspended (Ctrl+Z) session leaving the terminal in bracketed-paste mode
- Fixed stdio MCP servers receiving `server/discover` before `initialize`
- Fixed proxy connection refusals being reported as a generic network error
- Fixed `/model`/`/effort` cache-miss warning appearing when the prompt cache had already expired
- Multiple Remote Control fixes (per-task Stop, session env var inheritance, crashed-session reuse, transcript sync, model-pick sync, reconnect-on-hiccup, sign-out reporting)
- Fixed `ListAgents`/`SendMessage` reporting "Remote Control is not connected" in `claude remote-control`/Desktop/IDE-hosted sessions; fixed exposure of the idle pre-warmed worker
- Cross-session messaging: refused/dropped-inbox messages now report failure to sender instead of silently vanishing

## Codex CLI Changes

### New Features
- Added an interactive `codex agents` dashboard for searching, starting, opening, renaming, and stopping tasks, with configurable shortcuts
- Added `/cd`, `/pwd`, and `/cwd` commands for managing the working directory in TUI sessions
- Added `codex queue` for sending messages to existing local or remote sessions
- Expanded Vim editing with character replacement and more change motions (`cw`, `c$`, `cc`)
- `codex doctor` now diagnoses endpoint protection, network/proxy failures, desktop app state, and update connectivity
- SDK users can now pass exact CLI config overrides and select `max` or `ultra` reasoning effort

### Changed
- Queued messages now wake idle sessions reliably, resolve duplicate session names more usefully, and preserve pasted/deferred command semantics
- Resumed and forked threads now restore their active permission profile instead of silently falling back to defaults

### Fixed
- Fixed duplicate sub-agent activity and tightened TUI routing for sub-agent notifications/approvals
- Realtime WebRTC sideband connections now reconnect after unexpected transport loss without dropping pending output
- Inline TUI history now remains available in Windows Terminal scrollback
- Inactive TUI thread replay buffers are now bounded to prevent excessive retained streamed output
