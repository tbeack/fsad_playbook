# 2026-10-16 — Claude Code v2.1.301 / Codex rust-v0.163.0

## New Features (Claude Code v2.1.301)
- Added `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`: unattended retry mode ends a request when a usage-limit reset is too far away instead of waiting → **Affects:** Env vars table (retry watchdog section)
- Added `%` motion to vim mode: jump to matching bracket, alone or with d/c/y → **Affects:** No playbook impact (no dedicated vim motions section)
- Added `rows` to a mod's `Input`: a multi-line text field in the terminal, Enter submits, Shift+Enter or backslash+Enter starts a new line → **Affects:** Mods section mods API note
- Added `classifier_verdict` and `permission_mode` to OpenTelemetry `tool_decision` events → **Affects:** Monitoring events table `claude_code.tool_decision` row
- Added `classifier_category` to OpenTelemetry `tool_decision` events (requires `OTEL_LOG_TOOL_DETAILS=1`) → **Affects:** Monitoring events table `claude_code.tool_decision` row

## Fixed (user-visible behavior)
- Fixed `fable` and `best` model alias erroring when the newest Fable model is not available to an organization: Claude Code now retries once on the previous Fable model → **Affects:** Model aliases table (`fable` and `best` rows)
- Fixed VSCode LaTeX math rendering, diagnostics, and panel reload → **Affects:** No playbook impact

## Improved (Claude Code v2.1.301)
- Improved switching to a model with a smaller context window: a conversation too long for the new model is now summarized by the previous model first → **Affects:** Context management section
- Improved rendering performance for long-running subagents (incremental progress updates) → **Affects:** No playbook impact

## New Features (Codex rust-v0.163.0)
- Open `/config` to search preferences across categories and change settings immediately → **Affects:** Codex cheat sheet (new `/config` row)
- Send a follow-up while Codex is responding to steer immediately; interrupting also stops Code Mode cells → **Affects:** Codex cheat sheet (`instant_interrupt` already documented; minor enhancement)
- Configure a leader key in `/keymap`; default is `Ctrl+X`; voice mute moves to `F9` → **Affects:** Codex cheat sheet `/keymap` row

- Codex can run independent read-only tools in parallel (skill, memory, conversation-history lookups) → **Affects:** No specific playbook section
