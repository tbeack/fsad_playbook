# 2026-09-04 — Claude Code v2.1.260 / Codex CLI rust-v0.153.2

## Claude Code Changes

### New Features
- Diff panel opens beside the conversation in fullscreen mode and shows uncommitted changes live as Claude edits; toggle with `/diff` → **Affects:** Cheat Sheet `/diff` row (Update existing)
- `/cost` and the status line's `prompt_cache` field now include a likely cause for prompt-cache misses (tool definitions / system prompt changed, idle past TTL) → **Affects:** Cheat Sheet `/usage` row (Update existing)
- `/reload-plugins` now available in headless sessions (Desktop / SDK command lists) → **Affects:** Cheat Sheet `/reload-plugins` row (Update existing)
- Text form of `/advisor` (`/advisor`, `/advisor <model>`, `/advisor off`) for desktop app, Remote Control and headless (`-p` / Agent SDK) sessions → **Affects:** Cheat Sheet — no `/advisor` row exists (New row)
- `oidc.scope_on_refresh` and newer Claude Desktop keys (`userPluginMarketplacesEnabled`, `userPluginUploadsEnabled`) in Claude apps gateway policy blocks → **Affects:** No playbook impact (gateway admin internals)

### Changed
- `ctrl+l` / `cmd+k` in fullscreen mode now clear the transcript view like a terminal `clear` (scroll up for earlier messages) → **Affects:** Cheat Sheet keyboard shortcuts `Ctrl+L` row (Update existing)
- Commands typed at the `!` bash-mode prompt run outside the sandbox even under strict sandbox mode (`sandbox.allowUnsandboxedCommands: false`) → **Affects:** Power Usage sandbox settings table (Update existing)
- Claude in Chrome follows the organization's Claude in Chrome admin setting — when off, `--chrome`, `/chrome` and the browser tools are unavailable → **Affects:** Power Usage Chrome Integration collapsible (Update existing)
- Removed the one-hour time limit on background commands started by subagents; they run until exit or stopped, matching the main session → **Affects:** Power Usage Monitor Tool collapsible (Update existing)
- Improved auto-compact for 1M-context models: Opus and Fable sessions compact shortly before the 1M-token limit; recovery compaction no longer times out at 10 minutes → **Affects:** Power Usage context-management list (Update existing)
- `/ultrareview` / `claude ultrareview` wait up to 45 minutes (previously 30) for long-running cloud reviews → **Affects:** Cheat Sheet `/ultrareview` row (Update existing)
- `/effort` on Claude Fable 5.1 no longer invalidates the prompt cache when changed mid-session → **Affects:** Cheat Sheet `/effort` row (Update existing, folded into CBP-516)
- Permission rules with text after the closing parenthesis (`Bash(ls) x`) now reported as invalid settings → **Affects:** No playbook impact (error-reporting only)
- Managed CLAUDE.md (`claudeMd`) no longer triggers the security approval dialog → **Affects:** No playbook impact (playbook does not cover `claudeMd` managed setting)
- Claude apps gateway `orgPluginSettings` list form, nested-field validation, Bedrock CountTokens → **Affects:** No playbook impact (gateway internals)
- `--kill-session-after-min` releases paused sessions instead of killing them → **Affects:** No playbook impact (self-hosted runner flag not covered)
- Reverted 2.1.259 change applying `Read()` deny rules to Bash arguments → **Affects:** No playbook impact (behavior was never documented in the playbook)
- Workflow `agent({schema})` up-front rejection of unsatisfiable schemas; background-session deletion message improvements → **Affects:** No playbook impact
- Bundled `claude-api` skill: Go/Java/C# code samples moved to current-generation model IDs → **Affects:** No playbook impact (playbook only documents `/claude-api upgrade` and `cost-optimize` sub-commands, not the sample code)
- [VSCode] Selected effort level now shown in the footer model pill → **Affects:** No playbook impact (playbook does not enumerate VS Code footer pills)
