# 2026-11-20 — Claude Code v2.1.329 + Codex rust-v0.171.0

Claude Code v2.1.329 is new (up from v2.1.328). Codex CLI rust-v0.171.0 is new (up from rust-v0.170.0, via the npm `@openai/codex` registry; release notes fetched via `WebFetch` since the GitHub API is out of scope for this session's repository access).

## Claude Code v2.1.329

### New Features / Behavior Changes

- Added this session's scheduled tasks, `/loop` wakeups, the goal, and this conversation's forks to `/tasks`; `x` stops one after asking. → **Affects:** Claude Best Practices — `/tasks` row (Update existing)
- Changed "Exit and stop tasks" to end the session's scheduled tasks so they don't run again on resume, unless you exit while Claude is responding; most scheduled tasks saved by earlier versions need to be scheduled again in a new signed-in session, though `--resume` of their own session still runs them. → **Affects:** Claude Best Practices — `/schedule` row (Update existing)
- Changed `/code-review` with no target on most models to review the whole branch against the default branch instead of just the current diff, and fixed it losing the diff on multi-commit branches. → **Affects:** Claude Best Practices — `/code-review` row (Update existing)
- Changed auto mode to run `git status` less often so most requests wait less in large repositories; a git command that discards changes may be blocked until the working tree is checked. → **Affects:** Claude Best Practices — Auto Mode callout (Update existing)
- Added support for turning on Code Mode while OpenTelemetry events and metrics are enabled; each tool call the code makes sends its events, tracing still keeps it off. → **Affects:** Claude Best Practices — Code Mode collapsible (Update existing)
- Reviewed and deferred as no/low playbook impact at this scope: the trust-dialog hooks-location warning, the managed-settings hook-load failure warning, the `/mcp` "Server message" row, the `/status` marketplace auto-update row, the Agent tool `effort` fix for named teammates, and the large volume of other bug fixes, terminal/display fixes, VS Code–specific fixes, and internal reliability/memory/performance improvements reviewed this cycle (Keychain sign-out handling, `/terminal-setup` file corruption fixes, Code Mode memory/timeout fixes, Remote Control session restarts, self-hosted runner git/MCP fixes, etc.) — none rose to playbook-documentation relevance at this scope.
