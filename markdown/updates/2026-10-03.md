# 2026-10-03 — Claude Code v2.1.288

## Claude Code v2.1.288 (new since v2.1.287)

## Codex

No new Codex release. Current version: rust-v0.160.0 (unchanged since 2026-10-02).

### New Features
- Added `$.ui.selection()` for mods: returns text last selected in fullscreen and (when within one row) that row → **Affects:** Claude Best Practices (Plugins / Mods API) — deferred, mod-author niche
- Added built-in `gh api` to cloud sessions with no GitHub CLI; fixed control-character injection from file names, jq filters, or GitHub errors → **Affects:** No playbook impact
- Added Ctrl+C draft recovery: pressing Up on an empty prompt after Ctrl+C restores the cleared draft, including pasted text and images → **Affects:** Claude Best Practices (Keyboard Shortcuts cheat sheet)
- Added re-authenticate prompt when an MCP server requests more OAuth scope mid-call → **Affects:** No playbook impact (behavior change, no user-visible config)
- Added `--max-findings <n>|all` to `/code-review`: report more or fewer findings than the usual limit; pass `--max-findings default` to reset; choice is reused across invocations → **Affects:** Claude Best Practices (Slash Commands cheat sheet)
- Added Ctrl+F to find a session by name in the agents view; Alt+↑/↓ to jump between groups; both (and rename) can be rebound in keybindings.json; Enter now opens the session whose name matches best → **Affects:** Claude Best Practices (Session & Resume cheat sheet)
- Added screen reader mode announcement of new permission mode when approving a plan → **Affects:** No playbook impact

### Changed
- Changed background command time limit to apply only in unattended sessions (`-p`, Agent SDK, CI, cloud); terminal, desktop, and VS Code sessions have no limit → **Affects:** Claude Best Practices (Monitor / background commands) — deferred, overflow
- Changed `claude project purge` to `claude purge`; old name still works and prints a notice → **Affects:** Claude Best Practices (Session & Resume cheat sheet)
- Changed `/autocompact` to save the auto-compact window per model → **Affects:** Claude Best Practices (minor, single-sentence note) — deferred, overflow
- Changed MCP URL prompts to wait for "I'm done, continue" before the tool call continues → **Affects:** No playbook impact (behavior change)
- Changed agents view `n:` filter so Enter opens the best-match session, not the top row → **Affects:** Claude Best Practices (covered by CBP-640)
- Changed `ANTHROPIC_DEFAULT_SONNET_MODEL` pin behavior in auto mode classifier → **Affects:** No playbook impact

### Fixed (with playbook impact)
- Fixed session titles, memory recall, and prompt hooks failing on Mantle or gateways that reject structured outputs; added `CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS` → **Affects:** Claude Best Practices (Env Vars table)
- Fixed LSP tool calls hanging indefinitely; requests now time out after 60s (per-server `requestTimeout`) → **Affects:** No playbook impact (config key for LSP authors, too niche)
- Fixed PreToolUse and PermissionRequest hooks being skipped when matching failed; the call is now blocked → **Affects:** No playbook impact (correctness fix)

### Fixed (no playbook impact)
- Dozens of bug fixes for cloud sessions, Cowork, Remote Control, plugins, screen reader mode, Bedrock/Vertex auth, VSCode extension, Claude Tag, MCP — no playbook content changes needed.
