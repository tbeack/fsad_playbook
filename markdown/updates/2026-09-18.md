# 2026-09-18 — Claude Code v2.1.275 / v2.1.276

## New Features
- Added a send-now key (`ctrl+enter`, or `ctrl+x ctrl+s`) that interrupts the current turn and sends all queued messages at once; sent and queued messages show in gray until the model receives them → **Affects:** Keyboard Shortcuts table
- Added syncing of the skills and plugins enabled on your claude.ai account to terminal sessions signed in with it; opt out with `syncClaudeAiSkills: false` or `syncClaudeAiPlugins: false` → **Affects:** Skills page, Plugins collapsible
- Added `/plugin install <plugin> --marketplace <source>`, which offers to add the marketplace before installing the plugin → **Affects:** Plugins collapsible
- Added a startup warning when a configured `otelHeadersHelper` fails, so sessions that silently export no telemetry are noticed → **Affects:** Notable settings.json Keys, Monitoring collapsible
- Added the signed-in account to Claude apps gateway sign-in confirmation, shown in `/status` → **Affects:** No playbook impact (gateway sign-in confirmation UX, not a documented setting)

## Changed
- Changed scheduled and Run-now routine runs to save data to, and republish the page of, an artifact you can already edit without asking; public artifacts, first publishes, and deletes still ask → **Affects:** Notable settings.json Keys
- Removed the startup notice that told you a one-off scheduled routine had run since your last session → **Affects:** No playbook impact (removes a notice the playbook never documented)
- Changed the Artifact tool to ask for a one-word tab icon on a first publish instead of an emoji favicon → **Affects:** No playbook impact (Artifact-authoring UX outside this playbook's CLI/settings scope)
- Changed Claude in Chrome in auto mode to skip the extension's per-site check for classifier-approved calls → **Affects:** No playbook impact (Chrome extension behavior, not covered by this playbook)
- Changed plugins installed from an npm source to be fetched with `npm pack --ignore-scripts` and integrity-verified, so a package's install scripts no longer run → **Affects:** Deferred (see below)
- Fixed every request failing with `400 … Input tag 'advisor_20260301'` when `ANTHROPIC_BASE_URL` points at a proxy or gateway (v2.1.275 regression) → **Affects:** No playbook impact (regression fix within the same release window, restores already-expected behavior)

## Fixed
- Large batch of reliability and correctness fixes (memory-file cache misses after compaction, `--forward-subagent-text` dropping forked-skill subagent messages, plugin marketplace deletion on failed fetch, credential leakage in plugin/marketplace logs, zsh exit-code reporting in sandboxed Bash, Read tool hangs under memory pressure, resume/rewind crashes on malformed transcript data, Grep/Glob hangs over the 20MB cap, `SubagentStop` hook matcher over-firing, sandboxed Bash unable to write to `hooks/`/`config/` directories, `/update-config` writing `Write(path)` instead of `Edit(path)` rules, dead documentation URLs in the bundled claude-api skill, and more) → **Affects:** No playbook impact (bug fixes restoring already-documented or previously-broken-but-undocumented behavior)
- VS Code-specific fixes and improvements (Memory dialog editing, MCP dialog retry, proposed-change diff accept/reject buttons, Remote Control status, agent map, session list timestamps, and more) → **Affects:** No playbook impact (VS Code extension internals are outside this playbook's CLI-focused scope)
