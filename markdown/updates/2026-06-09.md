# 2026-06-09 — Claude Code v2.1.169

## New Features
- Added `--safe-mode` flag (and `CLAUDE_CODE_SAFE_MODE` env var) to start Claude Code with all customizations (CLAUDE.md, plugins, skills, hooks, MCP servers) disabled for troubleshooting → **Affects:** Cheat Sheet (CLI Launch Flags), Notable settings.json Keys
- Added `/cd` command to move a session to a new working directory without breaking the prompt cache mid-session → **Affects:** Cheat Sheet (Session, context & history)
- Added `disableBundledSkills` setting and `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS` env var to hide bundled skills, workflows, and built-in slash commands from the model → **Affects:** Notable settings.json Keys callout

## Changed
- `claude agents --json` fixed to stop omitting blocked and just-dispatched background sessions; added `--all` to include completed sessions, plus new `id` and `state` fields → **Affects:** Cheat Sheet (Info & account — claude agents row)
- `/workflows` now opens immediately even while a turn is in progress → **Affects:** No playbook impact (minor UX fix)
- The "CLAUDE.md is too long" warning threshold now scales with the model's context window → **Affects:** No playbook impact (internal improvement)
- Added a tip suggesting `claude agents` when running multiple concurrent sessions → **Affects:** No playbook impact (UI hint)

## Fixed
- Fixed Up/Down arrows jumping command history past wrapped rows → **Affects:** No playbook impact
- Fixed enterprise managed MCP policies not being enforced on reconnect → **Affects:** No playbook impact
- Fixed ~30-50ms UI stall at session start for macOS users → **Affects:** No playbook impact
- Fixed `claude -p` hanging on Windows (regression in 2.1.161) → **Affects:** No playbook impact
- Various background agents, Remote Control, Windows, and rendering fixes → **Affects:** No playbook impact
