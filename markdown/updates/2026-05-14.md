# 2026-05-14 — Claude Code v2.1.141

## New Features
- Added `terminalSequence` field to hook JSON output — hooks can emit desktop notifications, window titles, and bells without a controlling terminal → **Affects:** Hooks Deep Dive (Exit Codes & Decision Control — hook output section)
- Added `CLAUDE_CODE_PLUGIN_PREFER_HTTPS` env var — clone GitHub plugin sources over HTTPS instead of SSH, for environments without a GitHub SSH key → **Affects:** Subprocess Sandboxing env vars table
- Added `ANTHROPIC_WORKSPACE_ID` env var — scopes workload identity federation token to a specific workspace when the federation rule covers more than one → **Affects:** Subprocess Sandboxing env vars table
- Added `claude agents --cwd <path>` — scopes the session list to a directory → **Affects:** Cheat Sheet `claude agents` row

## Changed
- Rewind menu: added "Summarize up to here" to compress earlier context while keeping recent turns intact → **Affects:** Cheat Sheet `/rewind` row
- Background agents launched via `/bg` or `←←` now preserve the current permission mode instead of reverting to default → **Affects:** No playbook impact (internal behavior)
- Auto mode permission dialog now explains when a `permissions.ask` rule caused the prompt → **Affects:** No playbook impact (UI text change)
- `claude agents`: agents that finish work but leave a background shell running now move to Completed → **Affects:** No playbook impact (behavior change)
- Improved spinner feedback during long thinking periods → **Affects:** No playbook impact (UX only)
- Improved plugin menu navigation → **Affects:** No playbook impact (UX only)
- Restored "view diff in your IDE" option on file-edit permission prompts → **Affects:** No playbook impact (UI restoration)

## Fixed
- Multiple bug fixes for background agents, MCP servers, Windows, VSCode, Bedrock/Vertex — No playbook impact (internal)
