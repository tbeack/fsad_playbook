# 2026-05-14 — Claude Code v2.1.141

## New Features
- Added `terminalSequence` field to hook JSON output — hooks can emit desktop notifications, window titles, and bells without a controlling terminal → **Affects:** Hooks Deep Dive (Exit Codes section)
- Added `CLAUDE_CODE_PLUGIN_PREFER_HTTPS` env var — clone GitHub plugin sources over HTTPS instead of SSH, for environments without a GitHub SSH key → **Affects:** Subprocess Sandboxing env vars table
- Added `ANTHROPIC_WORKSPACE_ID` env var — workload identity federation, scopes minted token to a specific workspace → **Affects:** Subprocess Sandboxing hardening env vars table
- Added `claude agents --cwd <path>` — scope the session list to a directory → **Affects:** Cheat Sheet `claude agents` row
- Rewind menu: added "Summarize up to here" — compress earlier context while keeping recent turns intact → **Affects:** Cheat Sheet `/rewind` row
- Background agents launched via `/bg` or `←←` now preserve the current permission mode instead of reverting to default → **Affects:** No playbook impact (behavioral fix, no config surface)
- Auto mode permission dialog now explains when a `permissions.ask` rule caused the prompt → **Affects:** No playbook impact (UI improvement)
- `claude agents`: agents that finish work but leave a background shell running now move to Completed → **Affects:** No playbook impact (behavioral fix)
