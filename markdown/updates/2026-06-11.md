# 2026-06-11 — Claude Code v2.1.173

## New Features
- Sub-agents can now spawn their own sub-agents (up to 5 levels deep) (v2.1.172) → **Affects:** Power Usage (Multi-Agent / Parallel Subagents section)
- Amazon Bedrock reads AWS region from `~/.aws` config files when `AWS_REGION` isn't set; `/status` shows where the region came from (v2.1.172) → **Affects:** Claude Best Practices (Bedrock/Vertex setup note)
- Added a search bar when browsing a marketplace's plugins in `/plugin` (v2.1.172) → **Affects:** Cheat Sheet (/plugin row), Power Usage (Plugins collapsible)
- Added `model` attribute to `claude_code.lines_of_code.count` OTEL metric (v2.1.172) → **Affects:** Claude Monitoring section (OTEL metrics table)

## Fixed
- Fixed Fable 5 model names with a `[1m]` suffix not being normalized — Fable 5 includes 1M context by default, so the suffix is now stripped automatically (v2.1.173) → **Affects:** Cheat Sheet (model aliases table — note `fable[1m]` is redundant)
- Fixed a spurious "sandbox dependencies missing" startup warning on Windows when sandbox was enabled in settings (v2.1.173) → **Affects:** No playbook impact
- Various reliability fixes for agents, sessions, model restrictions (v2.1.172) → **Affects:** No playbook impact
