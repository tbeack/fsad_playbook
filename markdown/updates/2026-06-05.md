# 2026-06-05 — Claude Code v2.1.165

## Summary
Latest release is v2.1.165. Substantive changes came in v2.1.163; v2.1.164 had no changelog entry and v2.1.165 was bug fixes only.

## New Features (from v2.1.163)
- Added `requiredMinimumVersion` and `requiredMaximumVersion` managed settings — Claude Code refuses to start outside the allowed version range → **Affects:** Claude Best Practices (Managed Settings / Config Cascade)
- Added `/plugin list` command with `--enabled`/`--disabled` filters → **Affects:** Cheat Sheet `/plugin` row and Plugins collapsible
- Added "c to copy" shortcut to `/btw` copies raw markdown to clipboard → **Affects:** No playbook impact (`/btw` is not documented in the playbook)
- Hooks: Stop and SubagentStop can now return `hookSpecificOutput.additionalContext` to give Claude feedback and keep the turn going without a hook error label → **Affects:** Cheat Sheet Hooks tables (Stop + SubagentStop rows)
- Skills: added `\$` escape syntax to include a literal `$` before a digit in command bodies → **Affects:** Building Skills section (Skill Invocation card / argument substitution)

## Changed
- stdio MCP servers now receive `CLAUDE_CODE_SESSION_ID` on `--resume` → **Affects:** No playbook impact (note already present in env vars table for hooks)
- Clearer descriptions for built-in commands/skills in the / menu → **Affects:** No playbook impact

## Fixed
- Various bug fixes (bazel `$TMPDIR`, Windows `EEXIST`, hook `if:` conditions, deny rules, etc.) → **Affects:** No playbook impact
