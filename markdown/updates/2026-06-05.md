# 2026-06-05 — Claude Code v2.1.165

## New Features
- `requiredMinimumVersion` and `requiredMaximumVersion` managed settings — Claude Code refuses to start if its version is outside the allowed range and directs the user to an approved version → **Affects:** Config Cascade / Notable settings.json Keys callout
- `/plugin list` command now accepts `--enabled`/`--disabled` filters → **Affects:** Cheat Sheet / Configuration Commands table

## Changed
- Hooks: `Stop` and `SubagentStop` hooks can now return `hookSpecificOutput.additionalContext` to give Claude feedback and keep the turn going without being labeled a hook error → **Affects:** Cheat Sheet / Core hooks table and Agent & task hooks table
- Skills: added `\$` escape syntax to include a literal `$` before a digit in command bodies → **Affects:** Skills / string substitutions note
- `claude agents` dispatching from the state-grouped view now starts the session in the directory the agent view was opened from → **Affects:** No playbook impact (behavioral polish)
- Background agent sessions now update to a new Claude Code version in the background → **Affects:** No playbook impact (operational improvement)
- Clearer descriptions for built-in commands and skills in the / menu → **Affects:** No playbook impact
- `stdio MCP servers now receive the same CLAUDE_CODE_SESSION_ID as hooks/Bash on --resume` → **Affects:** No playbook impact (internal plumbing)
- Added "c to copy" shortcut to `/btw` to copy raw markdown to clipboard → **Affects:** No playbook impact (minor UX shortcut, /btw not documented)

## Fixed (v2.1.163, v2.1.165)
- Fixed `claude -p` hanging forever after final result when a backgrounded command never exits → No playbook impact
- Fixed `claude -p` failing with "ANTHROPIC_API_KEY required" on Bedrock/Vertex/Foundry with `CI=true` → No playbook impact
- Fixed bash commands failing under bazel and EDR-protected Go workflows (`$TMPDIR` regression) → No playbook impact
- Fixed hook `if: "Bash(...)"` conditions firing on every Bash command containing `$()` or `$VAR` → No playbook impact
- Fixed deny rules on home-directory paths not blocking Bash commands referencing via `$HOME` → No playbook impact
- Fixed various `claude agents` UI bugs → No playbook impact
- v2.1.165: Bug fixes and reliability improvements → No playbook impact
