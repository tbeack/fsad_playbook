# 2026-09-09 — Claude Code v2.1.266

## Claude Code Changes

Covers `v2.1.264` (no release) through `v2.1.266`, i.e. the `2.1.265` and `2.1.266` CHANGELOG.md entries, since the last recorded version was `v2.1.263`.

### New Features
- `--plugin-dir` now accepts a folder containing multiple plugin subfolders: each child folder with its own manifest is loaded, and children added or removed while Claude Code is running are picked up live (v2.1.265)
- Added a 1 GB cap on tool results saved to disk; the in-conversation preview now says the saved file was truncated when the cap is hit (v2.1.265)

### Changed
- Slash commands typed mid-prompt now show matches in a list (`Tab` opens it outside fullscreen) instead of a single suggestion; plugin skills are now found by their bare name (v2.1.265)
- `/workflows` agent detail view: tool calls marked running/failed/done, subagent's task list shown when it has one, `Enter` unfolds a listed call's inputs/results (v2.1.265) — minor UI/UX polish on an already-documented command; not turned into a task, see Deferred
- `--worktree` startup on large repositories now checks out worktrees in parallel on git 2.32+ (v2.1.265) — internal performance improvement, no doc action
- Various internal/managed-settings and enterprise-gateway changes (`forceLoginGatewayUrl`, plugin display metadata preference, Claude apps gateway OTLP export path) — no user-facing playbook action

### Fixed
- Fixed a 2.1.265 regression where the undocumented `CLAUDE_CODE_USE_GATEWAY` env var began forcing Cloud-gateway sign-in even when API-key/`apiKeyHelper`/custom-auth-header configs were set; reverted to prior (ignored-unless-both-set) behavior (v2.1.266)
- Large batch of internal reliability/bug fixes in 2.1.265 (prompt-cache reuse on subagent resume, `/model opusplan[1m]` rejection, syntax highlighting glitches, fullscreen transcript jumping, plugin symlink containment on macOS, Windows AppContainer sandbox file-tool failures, MCP HTTP/SSE fallback, non-interactive `cd` persistence, and more) — all restore previously-expected behavior; none change documented playbook guidance
