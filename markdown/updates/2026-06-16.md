# 2026-06-16 — Claude Code v2.1.178

## New Features
- Added `Tool(param:value)` syntax for permission rules to match a tool's input parameters (with `*` wildcard), e.g. `Agent(model:opus)` to block Opus subagents → **Affects:** Claude Best Practices / Config Cascade (Notable settings.json Keys callout)
- Skills in nested `.claude/skills` directories now load when working on files there; on a name clash, the nested skill appears as `<dir>:<name>` so both stay available → **Affects:** Building Skills section
