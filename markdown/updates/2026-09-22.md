# 2026-09-22 — Claude Code v2.1.280

Claude Code: v2.1.278 → v2.1.280 (new). Codex: rust-v0.155.1 (unchanged).

## New Features

- Added Claude Opus 5.5 (`claude-opus-5-5`), now the default Opus model — 1M context, $4/$20 per Mtok, $0.20/Mtok cache reads → **Affects: Model Selection (model comparison table + aliases)**
- Added `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` env var — changes the 2,048-character cap on MCP tool descriptions and server instructions for every MCP server in the session → **Affects: Notable Environment Variables table**
- Added hook output sizes and oversized-output count to the `hook_execution_complete` OpenTelemetry event → **Affects: Monitoring / OTel section (minor)**
- Added mouse support to more lists in fullscreen mode: the wheel scrolls the `/skills` list, and a skill's state options in `/plugin` can be clicked → **Affects: No playbook impact (UX improvement)**
- [VSCode] Added `/status`, `/sandbox`, `/chrome`, `/export`, `/skills`, `/plan` commands → **Affects: No playbook impact (VSCode-only, no dedicated commands table in practices.html)**

## Changed

- Changed the default model on Pro and Team Standard plans from Sonnet to Opus, matching Max, Team Premium, and Enterprise → **Affects: Model Selection (default alias row)**
- Changed `PermissionRequest` hooks: an agent-type hook no longer runs there; it now shows an error pointing to command or http hooks → **Affects: Hooks documentation (PermissionRequest table row + policy engine note)**
- Reverted `ctrl+l` / `cmd+k` in fullscreen mode clearing the transcript view (added in v2.1.260); they redraw the screen again → **Affects: Keyboard Shortcuts table**
- Changed the default model on Pro and Team Standard from Sonnet to Opus → **Affects: Model Selection (default alias row)**

## Fixed

- Fixed auto mode retrying an action over and over when a safety check declined to review it; the action is now denied once → **Affects: No playbook impact**
- Fixed Ctrl+C or Ctrl+D pressed twice in most dialogs quitting Claude Code instead of closing the dialog → **Affects: No playbook impact (keyboard fix)**
- Fixed Write calls failing validation when a model sends `path`, `file_text`, `file_content` or stray `description` → **Affects: No playbook impact (tool reliability fix)**
- Fixed resumed fork subagents rebuilding their tool list instead of re-sending the one they first used, which broke prompt caching → **Affects: No playbook impact (internal fix)**
- Fixed skills in `~/.claude/skills/` being moved to trash when a `manifest.json` in that folder listed their names → **Affects: No playbook impact (bug fix)**
- Many more fixes (dialogs, mouse, rendering, MCP, plugins, remote control, cloud sessions) → **Affects: No playbook impact**
