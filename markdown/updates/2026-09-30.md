## Claude Code v2.1.285

### New Features

- Added `CLAUDE_CODE_DISABLE_WEB_FETCH` environment variable to turn off the WebFetch tool → **Affects:** Notable Environment Variables table
- Added `claude --desktop` to open the Claude desktop app on the current directory, or on a session with `--continue` / `--resume <id>` → **Affects:** Session & resume Cheat Sheet flags table
- Added `claude plugin configure <plugin>` to show a plugin's options and which are unset, or save new values read from stdin with `--values-stdin` → **Affects:** Plugins collapsible
- Added `<server>.<key>=<value>` to `claude plugin install --config`, so a bundled `.mcpb` MCP server's own settings can be set at install time → **Affects:** Plugins collapsible
- Added `allowedProviders` managed setting to limit which API providers a machine may use (Anthropic API, a custom endpoint, Bedrock, Mantle, Vertex AI, Foundry, Claude Platform on AWS, or a Cloud gateway) → **Affects:** Notable settings.json Keys
- Added `CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES` environment variable to cap re-sends of a non-streaming fallback request that timed out → **Affects:** Notable Environment Variables table

### Changed

- Changed `claude -p` and Python Agent SDK sessions on third-party providers or with telemetry off to start in auto mode when no permission mode is configured, like interactive sessions; `--permission-mode` still overrides it — extends the v2.1.284 interactive-terminal/VS Code auto-mode-by-default change to headless and SDK sessions in this narrower case → **Affects:** Auto Mode Is Now the Default Starting Mode callout
- One-time offer to make auto mode the default permission mode now also shows on third-party providers and with telemetry off; `/recap` decline notice relayed from a routine/webhook/chat thread; `/artifacts` filter tab relabeling; Code Review PR reviews and `/ultrareview` running when `disableWorkflows` is on unless a machine admin sets it; various narrow enterprise/gateway/`/ultrareview` git-plumbing changes → No playbook impact (enterprise/internal scope, or too narrow for current doc depth)

### Fixed / Removed

- Large batch of reliability fixes: cloud session artifact-update conflicts after compaction, plugin/marketplace SSH config, managed-settings read failures, remote-control file-attachment retries, mid-session model switches, redacted-log URL passwords, worktree/`/teleport` SSH prompts, MCP server toggling, `--permission-prompt-tool` for background subagents, `claude mcp` output formatting, sandbox auto-allow over-prompting, fork-subagent permission-mode inheritance, and dozens more terminal/VSCode/cloud/Slack/Code-Review fixes → No playbook impact (internal reliability, UI polish, or edge cases not covered at this level of detail)
