# 2026-09-11 — Claude Code v2.1.269

## Claude Code Changes

### New Features
- `claude plugin eval`: run a plugin's eval suite against Claude Code and get scored, reproducible results (JSON + HTML report); see `claude plugin eval --help`.
- `/output-style [name]`: list and switch output styles directly, including over Remote Control and in cloud/headless sessions.
- `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS` (1–256): raises the Workflow tool's per-run concurrent agent limit for inference-bound fan-outs.
- `bashEditDiffEnabled` setting: shows a diff of file edits a Bash command made, in the Bash tool result.
- `OTEL_METRICS_INCLUDE_REPOSITORY`: tags OpenTelemetry metrics events with `vcs.*` repository attributes; commit events also get `vcs.ref.head.*`.
- `CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS`: extends the LLM gateway `/v1/models` discovery timeout (default 3s).
- Spinner tip suggesting `/focus` to view just the prompt, a one-line work summary, and the response.

### Changed
- `/ultrareview --post` now posts the PR comment directly when findings arrive and prints the comment link, instead of starting a second cloud session to post it.
- Artifact database reads now save into the session scratchpad, so they no longer stop for working-folder approval.
- Skills synced from claude.ai in cloud sessions are now named `anthropic-skills:<name>`, matching Claude Desktop; the bare name still works when nothing else uses it.

### Fixed
- Numerous terminal, prompt-cache, MCP, headless-session, and plugin-related fixes (see upstream CHANGELOG for the full list — mostly internal/no playbook impact). VS Code extension, Claude Code on the web, and Claude Tag (Slack) changes are out of scope for this CLI-focused playbook.
