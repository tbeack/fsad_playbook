# 2026-11-10 — Claude Code v2.1.321 / v2.1.322

Claude Code v2.1.322 is new (up from v2.1.319). Versions v2.1.320 and v2.1.321 were also released since the last check; v2.1.320 has no changelog entries (internal/skipped), so v2.1.321 and v2.1.322 are both reviewed below. Codex: rust-v0.167.0 (unchanged).

## Claude Code v2.1.321

### New Features
- Added Claude Fable 5.2 (`claude-fable-5-2`), now the default Fable model — 1M context, $8/$40 per MTok, $0.20/Mtok cache reads. Saved Fable 5.1 picks move to `fable` automatically (Pro/Max at once; Team/Enterprise once the org allows it); `/model claude-fable-5-1` switches back. → **Affects:** Claude Best Practices — model lineup table, model aliases table, Key Dates callout, `ultrathink` comment
- Added `--settings <file>` to `claude remote-control`, applying a settings file to every session it starts; a file change takes effect on the next restart. → **Affects:** Claude Best Practices — Cross-device cheat-sheet row, Remote Control & Cross-Device collapsible
- Changed mods Claude writes to turn on without asking in auto and bypass modes (even under managed `allowUnsandboxedCommands: false` / `allowManagedDomainsOnly`), and not to load in `dontAsk` mode; changed mods' own tool calls (`$.tool.call`, `$.mcp.call`) to raise no permission prompt at all, even under ask rules or `dontAsk`/`-p` runs — deny rules and org policy still apply. → **Affects:** Claude Best Practices — Mods "Install, Trust, and Turn Off" section
- Fixed MCP OAuth requests sending secrets such as refresh tokens to another host when a server redirected them; fixed a case where a read-only Bash command ran outside the sandbox without a permission prompt; fixed a case where Bash permission checks judged a file write from the wrong folder and didn't prompt; fixed deny rules and protected-file prompts not applying to the file a `cp`/`mv` into a directory writes. → **Affects:** No playbook impact — patched vulnerabilities, not new user-facing behavior to document; the playbook already states to stay current on updates.
- [VSCode] Added a warning above the prompt box when both an auth token and an API key are set. → **Affects:** No playbook impact (narrow VS Code config-conflict edge case, deferred)
- Changed the `/model` picker: "More models" is now an unnumbered row below every other, and older models open under it without renumbering the rest. → **Affects:** No playbook impact (minor picker UI detail)
- Large volume of other Windows, Remote Control, Claude Desktop, OpenTelemetry, and gateway-specific fixes reviewed — none rose to playbook-documentation relevance at this scope.
