# 2026-10-14 — Claude Code v2.1.299

## Summary

Claude Code jumped from v2.1.296 to v2.1.299 (v2.1.297 and v2.1.298 were never publicly released). Codex remains at rust-v0.162.1 (unchanged).

## New Features

- Added **idle compaction**: a 200K+ token conversation left idle for ~54 minutes is auto-compacted before its 1-hour prompt cache expires. Threshold configurable via `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS`; disable with `"idleCompaction": false` in settings.json (requires v2.1.290+). → **Affects:** Claude Best Practices — Context Management
- Added `CLAUDE_CODE_DISABLE_FILE_MENTIONS` env var: when set, Claude receives only the file *paths* of @-mentioned files rather than their contents, letting it decide which to read with its file tools. → **Affects:** Claude Best Practices — Hardening env vars table
- Added `/effort` and `/fast` in agent view to set what new sessions start with. → **Affects:** No playbook impact (agent view is niche; `/effort` already covered)
- Added `$.prompt.media` and `$.session.identity()` for mods installed by managed settings. → **Affects:** No playbook impact (mod authoring, not FSAD scope)
- Added `--shutdown-drain-sec` to `claude self-hosted-runner orchestrator`. → **Affects:** No playbook impact (ops detail)
- Added `--disallow-tools` and `disallowed_tools` to `claude plugin eval`. → **Affects:** No playbook impact (plugin dev)
- Added `/usage` warnings for max effort, workflows, always-on context, and large tool results. → **Affects:** No playbook impact (enhancement to existing coverage)

## Changed

- `UserPromptSubmit` hooks now run before a skill or slash command expands. → **Affects:** No playbook impact (documented behavior refinement)
- MCP allow rules now reach only the named server. → **Affects:** No playbook impact (behavior clarification)
- WebFetch effort now follows caller's level rather than a fixed model. → **Affects:** No playbook impact
- Changed `turn.start` mod hook to also fire on subagent/teammate turns. → **Affects:** No playbook impact

## Fixed

- Many stability and correctness fixes (cloud sessions, Remote Control, sandboxing, mod hooks, MCP). → **Affects:** No playbook impact
