## Claude Code: v2.1.296 → v2.1.299 (new)

## New Features
- Added `CLAUDE_CODE_DISABLE_FILE_MENTIONS` env var: `@` file mentions pass paths to Claude, not file contents → **Affects:** Claude Best Practices (env vars table, @mention card)
- Added idle compaction: sessions idle for ~54 min with 200K+ tokens compact before the 1-hour cache expires → **Affects:** Claude Best Practices (auto-compact section, settings.json list, env vars table)
- Added `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` to configure idle compaction threshold → **Affects:** Claude Best Practices (env vars table)
- Added `"idleCompaction": false` in settings.json to disable idle compaction → **Affects:** Claude Best Practices (settings.json list)
- Added `/effort` and `/fast` in agent view to set what new sessions start with; a bare `/model`, `/effort`, or `/fast` opens a picker → **Affects:** Claude Best Practices (claude agents row)
- Added `/usage` warnings for max effort, workflows, always-on context, and large tool results → **Affects:** Claude Best Practices (/usage row)
