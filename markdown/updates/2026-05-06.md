# 2026-05-06 — Claude Code v2.1.131

## New Features
- Added `--plugin-url <url>` flag to fetch a plugin `.zip` archive from a URL for the current session → **Affects:** Cheat Sheet (CLI flags), Power Usage (Plugins)
- Added `CLAUDE_CODE_FORCE_SYNC_OUTPUT=1` env var to force-enable synchronized output on terminals that auto-detection misses → **Affects:** Power Usage (Subprocess Sandboxing env vars)
- Added `CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE`: auto-upgrades Claude Code via Homebrew or WinGet in the background → **Affects:** Power Usage (Subprocess Sandboxing env vars)
- Added `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` opt-in env var for gateway model picker discovery (was automatic in v2.1.126–2.1.128) → **Affects:** Cheat Sheet (`/model` row)
- `skillOverrides` setting now works: `off`, `user-invocable-only`, `name-only` modes → **Affects:** Building Skills (config reference)

## Changed
- `Ctrl+R` history picker now defaults to searching all prompts across all projects (restored pre-2.1.124 behavior); `Ctrl+S` narrows to current project or session → **Affects:** Cheat Sheet (keyboard shortcuts)
- Plugin manifests: `themes` and `monitors` should now be declared under `"experimental": { ... }` → **Affects:** Building Skills (frontmatter reference)
- Gateway `/v1/models` discovery is now opt-in via `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` → **Affects:** Cheat Sheet (`/model` row)
- Third-party deployments no longer see spinner tips pointing at first-party Anthropic surfaces → No playbook impact
- `claude_code.pull_request.count` OTel metric now counts PRs via MCP tools → No playbook impact (OTEL section doesn't document this metric)
- Policy refusal errors now include API Request ID → No playbook impact
