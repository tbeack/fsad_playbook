## Claude Code v2.1.332

### New Features / Behavior Changes

- Added a `PreSkillShellCommand` hook event that can refuse a skill or command's inline shell commands as it loads; on v2.1.331 and older, a settings file naming it opens a compatibility dialog at start. → **Affects:** Claude Best Practices — Hooks reference, Tool & permission hooks table (Add new row, bump event count to 31)
- Added skills from MCP servers (beta): they show as `server:skill` in the `/` menu; other skills keep their own names. → **Affects:** Claude Best Practices — Building Your Own Skills section (Add new note)
- Improved Claude in Code Mode to confirm before discarding worktree changes, to read artifact files before publishing them, and to update an existing artifact instead of creating a second one. → **Affects:** Claude Best Practices — Code Mode collapsible (Update existing)
- Added "Always deliver" to the prompt for held messages from other sessions. → **Affects:** Claude Best Practices — Agent Teams, cross-session `SendMessage` paragraph (Update existing)
- Reviewed and deferred as no/low playbook impact at this scope: the footer line for a flagged message on a different model, the OpenTelemetry `assistant_response` event, VS Code/Desktop Code tab save-failure and resumed-session notices, the Cyber Verification Program access-tier startup header, the `/schedule`/`/loop` cloud-offer wording change from "routine"/"cloud schedule" to "cloud scheduled task" (`/routines` itself is unchanged), the Claude apps gateway's built-in model-list swap (Sonnet 5.5 for Sonnet 4.5) and the various Bedrock/Google Cloud Agent Platform/Microsoft Foundry model-alias and step-down changes, the desktop Code tab OpenTelemetry `service.name` change, `CLAUDE_CODE_OAUTH_TOKEN`'s `oat02-` prefix, `claude self-hosted-runner setup`'s interactive environment-key prompt, PgUp/Home defaulting to No on destructive questions, the `/feedback` draft flow change, the tap-mode voice dictation timing change, and the very large volume of other bug fixes and VS Code-specific fixes reviewed this cycle — none rose to playbook-documentation relevance at this scope.
