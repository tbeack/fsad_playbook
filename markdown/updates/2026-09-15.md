# 2026-09-15 — Claude Code v2.1.273

## New Features
- Added `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` opt-in: sends `x-claude-code-request-class`, `x-claude-code-agent-type`, `x-claude-code-prev-tool-durations`, `x-claude-code-compaction`, and `x-claude-code-context-compacted` headers to LLM gateways → **Affects:** Notable Environment Variables table
- Added forking a session started with `claude --remote-control` or `/remote-control` from the Claude app; the fork runs as a background session on your computer → **Affects:** Remote Control & Cross-Device collapsible
- Added MCP server disconnect notification mid-session when automatic reconnection gives up, pointing at `/mcp` → **Affects:** No playbook impact (minor UX)

## Changed
- Changed `OTEL_LOG_TOOL_DETAILS=1` to also include real agent, skill, plugin and MCP server names on cost and token metrics → **Affects:** Monitoring collapsible (Opt-in Detail Levels callout)
- Changed auto mode on Bedrock, Vertex, and Foundry to use the local classifier by default; set `CLAUDE_CODE_AUTO_MODE_SERVER=1` to switch to the platform's server-side classifier → **Affects:** Notable Environment Variables table
- Changed sign-in with a Claude account to also request access to claude.ai plugins → **Affects:** No playbook impact (minor)

## Fixed
- Fixed context meter and auto-compact counting advisor-tool turns at roughly twice their real context size → **Affects:** No playbook impact (bug fix)
- Fixed `blockReadsOutsideWorkingDirectories` not prompting for Bash commands the checker cannot fully analyze → **Affects:** No playbook impact (bug fix)
- Fixed skills synced from claude.ai staying available after an org turns Skills off → **Affects:** No playbook impact (bug fix)
- Fixed `allowManagedMcpServersOnly`, `deniedMcpServers`, `disableClaudeAiConnectors` in MDM/managed-settings.json being ignored → **Affects:** No playbook impact (bug fix)
