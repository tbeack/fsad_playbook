# 2026-05-27 — Claude Code v2.1.152

## New Features
- `/code-review --fix` applies review findings to working tree; `/simplify` now invokes `/code-review --fix` → **Affects:** Cheat Sheet (update `/code-review` row)
- Skills and slash commands can now set `disallowed-tools` in frontmatter to remove tools while the skill is active → **Affects:** Building Skills / Frontmatter Reference
- Added `/reload-skills` command to re-scan skill directories without restarting → **Affects:** Cheat Sheet (configuration commands table)
- `SessionStart` hooks can return `reloadSkills: true` to re-scan skill directories → **Affects:** Hooks reference (SessionStart description)
- `SessionStart` hooks can set session title via `hookSpecificOutput.sessionTitle` → **Affects:** Hooks reference (SessionStart description / hookSpecificOutput docs)
- Added `MessageDisplay` hook event — lets hooks transform or hide assistant message text as displayed → **Affects:** Cheat Sheet hooks table + Hooks collapsible
- Added `pluginSuggestionMarketplaces` managed setting → **Affects:** No playbook impact (managed/enterprise-only)
- `claude plugin marketplace remove` now accepts `--scope user|project|local` → **Affects:** Minor CLI addition; no playbook impact
