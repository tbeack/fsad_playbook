# 2026-08-25 — Claude Code v2.1.245 (Codex CLI unchanged at rust-v0.149.1)

## Claude Code Changes

### New Features (v2.1.243)
- Added a Loops breakdown to `/usage`: per-loop run count, total tokens, tokens per run, and last run.
- Added `modelPicker` setting: curate the `/model` picker with an ordered, labeled list of models.
- Added `promptCacheTtl` and `subagentPromptCacheTtl` settings for independent main/subagent cache TTLs.
- Added `modelPricing` managed setting for org-contracted per-model rates in `/cost`, status line, telemetry.
- Added a keyless sign-in under `/login` → Anthropic Console ("Sign in with your Console account").
- Added a `Skipped sources` line to `/status` for managed settings sources present but not applied.
- Added a `managed` marker in `/mcp` and `/plugin` on claude.ai connectors whose auth is org-managed.
- Added a tip pointing claude.ai users without GitHub connected to `/web-setup`.
- Added a `/status` line showing whether GitHub is connected for Claude Code on the web.
- Added the model (and effort level) each subagent ran on to `/tasks` and the agent detail dialogs.

### Changed (v2.1.243)
- Sandboxed Bash tool prompt no longer lists allowed network hosts; Claude now attempts requests and you approve new hosts as they come up.
- `/model`, `/fast`, and `/effort` now also run immediately instead of queueing until the turn ends on Bedrock, Vertex, Foundry, and when telemetry is disabled.
- `/model` picker and bundled `claude-api` skill pricing display updated for Sonnet 5.
- Computer use on macOS now requires granting Finder via the access dialog for Dock/Finder clicks.
- Cross-session messaging inbox socket now closes connections with no complete line within 30s.

### Fixed (v2.1.243 — selected notable items; see Playbook Action Items)
- `/model` picker silently ignoring an Ultracode selection.
- `/resume` only listing the 50 most recent sessions (picker now loads more on scroll).
- Hook `if` conditions like `Bash(cat *)` false-firing on unrelated commands containing `$()`/backtick substitution.
- Plugin dependencies declared with a `marketplace` field never resolving when loaded via `--plugin-dir`.
- `/reload-plugins` keeping the LSP tool after the last LSP plugin is disabled (now also warns before an LSP change).
- Background subagents not waking when their last background Bash task completes.

### Fixed (v2.1.243/v2.1.245 — no action, internal reliability/bug fixes)
The remainder of the 2.1.243 "Fixed" list and the 2.1.245 release consist of internal reliability, crash, and UI bug fixes to existing (already-documented, or never-documented-because-internal) behavior, with no new user-facing workflow to describe and no existing playbook claim they contradict:
- v2.1.245: Fixed a crash on startup on Linux distributions shipping glibc 2.44 (Arch, CachyOS, Fedora Rawhide) — no action: pure crash fix, nothing to document.
- v2.1.243: remote MCP reconnect-after-drop fixes, MCP desktop sign-in redirect-URI fix, auto mode availability/tool-call timing fixes, cloud session resume/hook-notification fixes, cross-session messaging in rootless containers, text-hanging repaint bug, spellcheck-after-emoji bug, sessions-going-silent timeout, client-error rendering, workload identity federation token reuse, companyAnnouncements startup bug, `--agents` invalid-JSON handling, `/status` invalid-MCP-entry message, `/clear` session-name bug, Ctrl+R/history search malformed-entry bug, Ctrl+[ vim-mode bug, HTTPS_PROXY casing bug, sandbox network-violation detail dropping, rate-limit status line staleness, `claude --teleport` uncommitted-changes bug, `/web-setup` repeated-login-prompt bug, Claude in Chrome native-host bug, VSCode focus-view/permission-mode bugs, Remote Control `claude remote-control` recovery/stuck-session bugs, VSCode history trimming/telemetry-attribution improvements, and various startup/memory/binary-size performance improvements — no action: internal fixes/perf work, not new documented behavior.
