# 2026-08-13 — Claude Code v2.1.229 (via v2.1.231 latest tag) / Codex CLI no new release

## Claude Code Changes

Latest GitHub release tag is v2.1.231, but that release contains only one internal fix (MCP OAuth redirect URI). The prior release, v2.1.229, contains all of the user-facing changes for this cycle (`lastVersion` was v2.1.228, so both 2.1.229 and 2.1.231 entries were gathered).

### New Features
- Documented `claude remote-control --continue` for resuming the most recent Remote Control session
- Added plugin marketplace `command` sources: a local command (e.g. an IDE) prints the plugin directory, re-resolved each session and applied without a restart; `mode: "link"` uses it in place
- Improved workflow fan-outs to stagger same-prefix sibling agents so subsequent agents read the cached prompt prefix instead of re-paying it (`CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS=0` disables)
- Added server-supplied Claude Code hook support for self-hosted runner sessions, matching managed-environment behavior
- Added SSE keepalive pings to gateway streaming responses during long thinking pauses (Vertex/Bedrock)
- `ListAgents` now marks disconnected Remote Control sessions as `offline` and labels cloud sessions as `cloud`
- [VSCode] Added session groups in the sidebar — right-click to create/rename/delete; Cmd/Ctrl- or Shift-click to move several sessions
- [VSCode] Made the `/btw` side-question panel resizable by dragging its boundary

### Changed
- `/commit-push-pr` — git/gh commands with dangerous flags (`--force`, `--amend`, `--no-verify`, etc.) are no longer auto-approved
- Self-hosted runner Windows startup now requires an explicit `--base-dir`; no default checkout directory on Windows
- Sandbox: IPv6 literals in network domain lists are now bracketed (`[::1]:443`), ambiguous spellings enforced fail-closed and flagged by `/doctor`
- Improved "prompt is too long" errors to explain why automatic compaction could not recover
- `/login` now repeats the `CLAUDE_CODE_OAUTH_TOKEN` override warning after a successful login

### Fixed
- Fixed MCP OAuth sign-in failing with a redirect URI mismatch for servers using a pre-registered OAuth client (v2.1.231)
- Fixed MCP OAuth with strict authorization servers by using `127.0.0.1` instead of `localhost`
- Fixed long responses partly disappearing while streaming / printed twice in the terminal
- Fixed a crash to the error screen when a tool call had a non-string `glob`/`file_path`/`command` value
- Fixed a RangeError crash rendering a progress bar or markdown table in a very narrow terminal
- Fixed a crash on Windows referencing a file by an extended-length (`\\?\`) or UNC path
- Fixed auto mode failing on every tool call when `CLAUDE_CODE_ATTRIBUTION_HEADER` is disabled
- Fixed `/model` rejecting Sonnet/Opus 1M for claude.ai subscribers using a custom `ANTHROPIC_BASE_URL` gateway
- Fixed Remote Control clients showing a stuck working spinner after a slash command typed in the laptop terminal
- Fixed the Claude Code Review GitHub workflow completing without posting its review
- Fixed multi-second UI stalls after editing a file with thousands of IDE diagnostics
- Fixed a stray liveness file left by one-shot `claude plugin` commands
- Fixed dynamic workflows in CPU-limited containers using the host's core count instead of the container's limit
- Fixed a file-watcher handle leak after atomic file replacements; fixed an uncaught Windows scheduled-tasks watcher error
- Fixed SDK / `--input-format stream-json` sessions getting a 400 error on a whitespace-only message
- Fixed conversations exceeding the API's 32 MB limit retrying compaction pointlessly when no images/documents can be stripped
- Fixed OpenTelemetry export from Claude Desktop being rejected by the Desktop-managed gateway when it's also the telemetry endpoint
- Fixed self-hosted runner sessions exiting at startup when `managed-mcp.json` is deployed and the server delivers MCP servers
- Fixed self-hosted runner repository preparation hanging on a Git Credential Manager prompt
