# 2026-10-20 — Claude Code v2.1.304

## New Features
- `/auto-mode-setup` — guided setup that reads your project and recent sessions to teach auto mode about your environment; now also available on Bedrock, Vertex, Foundry, the Claude apps gateway, and telemetry-disabled sessions. → **Affects:** CBP-701
- `/claude-api managed-agents-secure` — compares a Managed Agents agent's settings against Anthropic's published security guide, without changing anything. → **Affects:** CBP-702
- `[Code Review]` Review levels — owners choose Quick, Standard (default), or Deep for the organization, with a per-repository override. → **Affects:** CBP-703
- `[Code Review]` Org-wide repository selection — admins can review every repository in a GitHub organization, including ones added later, without selecting them one by one. → **Affects:** CBP-703
- A warning on Pro/Max plans when resuming an inactive conversation would use a noticeable share of the 5-hour usage limit. → **Affects:** CBP-704
