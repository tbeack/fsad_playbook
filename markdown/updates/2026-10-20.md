# 2026-10-20 — Claude Code v2.1.304

## New Features
- Added `/auto-mode-setup`: a guided setup that reads your project and recent sessions to teach auto mode about your environment. Now also available on Bedrock, Vertex, Foundry, Claude apps gateway and telemetry-disabled sessions (v2.1.304). **Affects:** Cheat Sheet (slash commands table)
- Added `/claude-api managed-agents-secure`: compares a Managed Agents agent's settings with Anthropic's published security guide without changing anything (v2.1.304). **Affects:** Cheat Sheet (/claude-api commands group)
- Added Code Review levels for GitHub Code Review Agent: owners choose Quick, Standard (default), or Deep for the organization, and can set per-repository levels (v2.1.304). **Affects:** Claude Best Practices, section 10.5 Code Review Agent
- Added org-wide Code Review enrollment: a new admin setting reviews every repository in a GitHub organization, including ones added later, without selecting them one by one (v2.1.304). **Affects:** Claude Best Practices, section 10.5 Code Review Agent

## Changed
- `/reload-skills` now sends only new or changed skills to Claude after a compaction (previously re-sent the full list) (v2.1.304). **Affects:** Cheat Sheet (configuration commands table)
- Compaction now sends Claude the skill list again afterwards (v2.1.304). **Affects:** No additional playbook entry needed beyond the /reload-skills note.
- Tool search now on by default behind a custom `ANTHROPIC_BASE_URL` (v2.1.304). **Affects:** No playbook impact — there is no prior note saying it was off by default.

## Fixed
- Many bug fixes for mods, sandboxing, Remote Control, and other subsystems (v2.1.304). **Affects:** No playbook impact — internal/reliability fixes.
