# 2026-05-22 — Claude Code v2.1.148

## New Features
- None in this release window.

## Changed
- **Pinned background sessions** (`Ctrl+T` in `claude agents`) — pinned sessions stay alive when idle, are restarted in place to apply Claude Code updates, and shed only under memory pressure after non-pinned sessions → **Affects:** Cheat Sheet (Keyboard Shortcuts)
- **`/code-review` — `--comment` flag** — pass `--comment` to post findings as inline GitHub PR comments → **Affects:** Cheat Sheet (Slash Commands)
- **`/code-review` renamed from `/simplify`** — rename happened in v2.1.147, not v2.1.146 as previously documented → **Affects:** Cheat Sheet (Slash Commands, version reference correction)
- Improved auto-updater: retries transient network failures, reports specific error categories and OS error codes → No playbook impact
- Improved diff rendering performance for large file edits → No playbook impact
- Prompt history no longer records consecutive duplicate entries → No playbook impact

## Fixed
- v2.1.148: Bash tool returning exit code 127 on every command for some users (regression from v2.1.147) → No playbook impact
- Unknown slash commands in headless/SDK mode now show an error message → No playbook impact
- `/help` rendering broken on small terminals → No playbook impact
- Hook `if` conditions like `PowerShell(git push*)` never matching → No playbook impact
- Several other internal bug fixes → No playbook impact
