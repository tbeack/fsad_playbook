# 2026-09-24 — Claude Code v2.1.281

Claude Code: v2.1.280 → v2.1.281.

## Claude Code v2.1.281

### New Features

- `"attribution": false` in `settings.json` hides all commit and PR attribution entirely (broader than the existing `attribution.sessionUrl`); older CLI versions skip a settings file holding the bare boolean → **Affects:** Notable Settings list (new bullet)
- `/insights` gained an auto mode recommendation estimating how many permission prompts auto mode could have handled in recent sessions → **Affects:** `/insights` collapsible bullet list
- `--system-prompt-file <path>` / `--append-system-prompt-file <path>` — read the system prompt from a file instead of the command line → **Affects:** System prompt & config table (new rows), Self-Hosted Runner collapsible (compat note)
- MCP URL-mode elicitation, `claude plugin validate` MCP checks, Claude Desktop gateway policy/Bedrock upstream options (`assume_role`, `guardrail`), `telemetry.resource_attributes` → No playbook impact (enterprise gateway/admin internals outside current doc scope)

### Changed

- Auto mode: where classifier review runs server-side, read-only and sandboxed shell commands now also wait for that review and are blocked when flagged, instead of being auto-approved without a classifier round-trip → **Affects:** Notable Settings auto-mode bullet list (new bullet)
- `CLAUDE_CODE_AUTO_MODE_SERVER` now also applies on a direct Anthropic API connection (`0` opts out, `1` opts in) → No playbook impact (already documented as the v2.1.278 default; this is an internal scope clarification, not a new user-facing behavior)
- Dangerous-`rm` prompt in `--dangerously-skip-permissions`/auto mode now waits 2 minutes then denies with a rewrite hint (`CLAUDE_CODE_DISABLE_DANGEROUS_RM_TIMEOUT=1` to disable) → **Affects:** Subprocess Sandboxing paragraph
- Recursive `rm` targeting only command-substitution output (e.g. `rm -rf "$(pwd)"`) now prompts even with a matching Bash allow rule (`CLAUDE_CODE_DISABLE_SUBSTITUTION_RM_PROMPT=1` to disable) → **Affects:** Subprocess Sandboxing paragraph
- Send-now (`Ctrl+Enter` / `Ctrl+X Ctrl+S`) now moves the turn's running tools to the background instead of cancelling them → **Affects:** Keyboard Shortcuts table (row update)
- Self-hosted runners now pass system prompts as private files instead of command-line text, avoiding launch failures on large prompts; wrappers/hooks using `--system-prompt`/`--append-system-prompt` must switch to the file-based forms → **Affects:** Self-Hosted Runner collapsible

### Fixed / Removed

- Large batch of reliability fixes: session resume edge cases, prompt-cache preservation across proxies/gateways, retry-watchdog and rate-limit handling, sandboxed-path checks, vim mode motions, TUI/dialog key handling, Windows update races → No playbook impact (internal reliability, not user-configurable behavior)
- VS Code, Claude Code on the web, and Claude Tag (Slack) fixes (session history loading, routine triggers, Slack thread recovery, etc.) → No playbook impact (IDE/platform-specific bug fixes, not covered by this playbook's scope)
