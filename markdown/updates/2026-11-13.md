# 2026-11-13 — Claude Code v2.1.323 + Codex rust-v0.169.0

Claude Code v2.1.323 is new (up from v2.1.322). See PR #316. Codex rust-v0.169.0 is new (up from rust-v0.167.2).

## Claude Code v2.1.323

### New Features

- Added Code Mode, an experimental opt-in execution mode in which Claude writes JavaScript to call its tools instead of making one tool call per turn; see https://code.claude.com/docs/en/code-mode to turn it on, or to turn it off for an organization. → **Affects:** Claude Best Practices — Power Usage section, new collapsible (New content)
- Added `engines["claude-code"]` to `plugin.json`: a plugin outside its stated Claude Code version range is not installed, updated, or loaded, and install/update pick the newest version that fits. → **Affects:** Claude Best Practices — Power Usage → Plugins collapsible (Update existing)
- Added a start-up warning for Bash allow rules with a `*` in a variable's value, such as `Bash(PORT=* npm run dev)`. → **Affects:** Claude Best Practices — Notable `settings.json` Keys callout, next to the existing wildcard-before-subcommand warning (Update existing)
- Reviewed and deferred as no/low playbook impact at this scope: the hooks-progress heartbeat, `.docx` Artifact asset uploads, the `/diff` close hint, the usage-credits options menu, `CLAUDE_CODE_AUTO_MODE_MODEL` (Claude Desktop managed setting), the Perforce startup notice, `CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES`, `CLAUDE_CODE_RESUME_HINT_COMMAND`, `plugin install --json`'s `unsetOptionCount`, a mod pane's `isPromptCovered` prop, `claude plugin validate` TypeScript type-checking, and the large volume of bug fixes, VS Code / Claude Code on the web / Remote Control / Claude Tag / OpenTelemetry items reviewed this cycle — none rose to playbook-documentation relevance at this scope.

## Codex rust-v0.168.0 + rust-v0.169.0

### New Features (rust-v0.168.0)

- Enable `features.tui_workspace` to view a persistent side conversation pane beside the main chat; drag to resize or press `leader z` to zoom. → **Affects:** Codex Best Practices — Power Usage, new Terminal Workspace collapsible (New content)
- Browse model providers under Sessions → Model providers; set the default provider for new chats from the TUI. → **Affects:** Codex Best Practices — Multi-Provider Models section (Update existing)
- Attach audio recordings when using an audio-capable model; Codex skips rejected recordings and uses clip duration to budget context. → **Affects:** Codex Best Practices — Voice Conversations section (Update existing)
- Set `tui.notification_method = "osc777"` for OSC 777 terminal notifications with longer approval previews. → **Affects:** Codex Best Practices — Configuration Reference table (Update existing)

### New Features (rust-v0.169.0)

- Terminal workspace now supports multiple side-chat tabs; switch with keyboard/mouse, local side chats persist across restarts. → **Affects:** Codex Best Practices — Power Usage, Terminal Workspace collapsible (bundled with CBP-766)
- Search older tasks from the agent command center by name, prompt preview, or working directory. → **Affects:** Codex Best Practices — `codex agents` row and Interactive dashboard paragraph (Update existing)
- Add or edit custom model providers from the terminal; device-code gateway sign-in for SSH/headless environments. → **Affects:** Codex Best Practices — Multi-Provider Models section (bundled with CBP-768)
- `codex exec` and `codex review --trust`: untrusted dirs keep project config and MCP servers disabled even with `--sandbox workspace-write`. → **Affects:** Codex Best Practices — CI/CD Integration section (Update existing)

### Deferred (no playbook action)

- Animated GIF generation (`features.image_generation_animation`), image previews in tmux (Ghostty/Kitty), `Ctrl+S` diagnostic ZIP save, full-screen "Collapse turn details", Cloud connection image/archive on macOS+Linux — no playbook impact at this scope.
