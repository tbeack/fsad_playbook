# 2026-05-19 — Claude Code v2.1.144 / Codex CLI v0.131.0

## Claude Code Changes

### New Features
- `/resume` now includes background sessions (`claude --bg`) in the picker, marked with `bg`; elapsed duration shown in completion notifications for background subagents (e.g. "Agent completed · 3h 2m 5s")
- `/model` now changes the model for the current session only; press `d` in the model picker to set a default for new sessions
- `/usage-credits` added — renamed from `/extra-usage` (old name still works)
- `/plugin` browse and discover panes now show when a plugin was last updated
- `/bg` and `←`-detach now preserve directories added via `/add-dir`
- `/doctor` now shows exec-form example when a command hook is missing the `command` field

### Fixed
- Fixed startup hanging up to 75s when `api.anthropic.com` is unreachable — side-channel API calls now time out after 15s
- Fixed terminal display corruption in VS Code and long sessions
- Fixed macOS bg sessions crashing under Full Disk Access-protected folders
- Fixed MCP servers with paginated `tools/list` only returning first page
- Fixed Skill tool failing with permission error in headless mode
- Fixed `claude mcp list` silently failing when `.mcp.json` can't be parsed
- Fixed numerous background session lifecycle and Windows rendering bugs

## Codex CLI Changes

### New Features
- Enhanced TUI with richer session controls, blended token usage, and permissions/approval mode display
- Unified `@` mentions for files, directories, plugins, and skills in one picker (backed by app-server plugin metadata)
- Plugin workflows gained marketplace CLI commands, version-aware sharing, share checkout, and default-enabled plugin hooks
- Remote workflows: daemon-managed `codex remote-control`, runtime enable/disable APIs, status reads
- Python SDK moved to `openai-codex` / `openai_codex`, with pinned runtime-generated types and concurrent turn routing
- Added `codex doctor` for support-ready diagnostics across runtime, auth, terminal, network, config, and local state

### Fixed
- Fixed TUI interaction/rendering issues (URL wrapping, light-mode contrast, Shift+Enter in tmux)
- Hardened Windows sandbox behavior around deny-read rules and scoped write roots
- App-server startup safer with SQLite data preservation and recovery paths
- Git/auth reliability improvements
