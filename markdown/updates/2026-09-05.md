# 2026-09-05 — Claude Code v2.1.261

## Claude Code Changes

### New Features
- `/skill-doctor` shows which loaded skills go unused and what they cost in context, so you can prune them → **Affects:** Cheat Sheet — no `/skill-doctor` row exists (New row)
- `bashOutputMaxChars` and `taskOutputMaxChars` settings raise how much command/background-task output Claude receives inline before it is saved to a file, up to 128K characters → **Affects:** Notable settings.json Keys callout (New item)
- `--append-subagent-system-prompt-file` reads the subagent system prompt from a file, for prompts too large to pass on the command line → **Affects:** Cheat Sheet CLI flags table, System prompt & config (New row)
- `/status` and `claude doctor` gain an "Organization policy" line explaining why an org's managed policy could not be loaded (e.g. a proxy not passing the endpoint through) → **Affects:** Cheat Sheet `/status` row (Update existing)

### Changed
- Prompt word-editing keys now match Bash by default: `Ctrl+W` deletes back to whitespace, `Alt+F`/`Alt+D` stop/delete to word end, punctuation separates words; `keybindingFlavor` no longer has any effect → **Affects:** Cheat Sheet `Ctrl+W` row + Notable settings.json Keys `keybindingFlavor` item (Update existing, breaking change to a documented setting)
- Auto mode now treats a link that packs content into a public diagram renderer's URL as an upload to that site — no longer auto-approved unless asked for → **Affects:** Notable settings.json Keys, Auto mode built-in safety list (New item)
- Improved the dangerous-`rm` safety prompt to also catch `rm -rf` on positional parameters and inside double-quoted `sh -c` scripts → **Affects:** Subprocess Sandboxing paragraph (Update existing, extends CBP-469)
- Improved the `/model` picker and VS Code model pill to show a model's name instead of its raw Bedrock/Vertex/gateway ID → **Affects:** No playbook impact (display-only nuance, `/model` row doesn't enumerate this level of detail)
- Startup on Vertex AI with `GOOGLE_APPLICATION_CREDENTIALS` set no longer re-runs project discovery or spawns extra `gcloud` processes → **Affects:** No playbook impact (internal perf)
- Streaming performance: already-rendered blocks no longer re-checked by layout on each update → **Affects:** No playbook impact
- API no-response-headers retry now waits up to `API_TIMEOUT_MS` instead of 3 minutes → **Affects:** No playbook impact (infra edge case, not covered)
- Claude apps gateway 403 on managed settings load says Claude Code may not be enabled for the org, instead of advising a new sign-in → **Affects:** No playbook impact (gateway admin messaging)
- Machines with `forceLoginMethod: "gateway"` ignore a leftover API key or claude.ai login and ask for `/login`; Bedrock/Vertex/Foundry unaffected → **Affects:** No playbook impact (`forceLoginMethod` not covered)
- `/context` token counting falls back to a local estimate when the token-counting API is unavailable → **Affects:** No playbook impact

### Fixed
- Typed/pasted character ordering during fast input, `/add-dir <subdirectory>` on `/net` automounts, Bedrock setup wizard hangs and TLS-proxy model checks, plugin sync on cloud sessions, `[Image #N]` chip deletion, resumed sessions losing hook output around parallel tool calls, several Remote Control fixes (stale permission mode, stuck spinner, teleport double-upload, TLS-proxy event stream, stale effort level), SDK/cloud sessions ignoring an early Stop/interrupt, `gcpAuthRefresh` opening a browser unnecessarily, claude.ai connector retry on timeout, high CPU from a stuck background-agent wake retry loop, feature-flag version gating, `/usage` weekly-limit row dropping under rate limits, `claude -p --resume` malformed session ID, terminal progress indicator staleness, a layout glitch, gateway client-IP/OTEL-format fixes, Desktop/web busy-state, Claude in Chrome file upload in local Cowork sessions, offline Remote Control `SendMessage` delivery status, plugin-install-hint leakage, agent-team teammates re-sending first-turn announcements, many `[VSCode]` fixes → **Affects:** No playbook impact (stability fixes; VSCode-specific items out of playbook scope per prior cycles)
