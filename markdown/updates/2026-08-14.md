# 2026-08-14 — Claude Code v2.1.232 / Codex CLI (no new release)

## Claude Code Changes

### New Features
- Subagent forking is now on by default: a `subagent_type: "fork"` subagent inherits the full conversation and prompt cache, and non-teammate agent spawns in interactive sessions now run in the background by default
- Type `@` in the prompt to mention another Claude session by name; Claude then uses `SendMessage` to reach that session directly
- Added `/config` rows for "Dialog expiry" and "Messages from your other sessions" (cross-session inbound accept/hold/refuse)
- Added GitLab support to plugin marketplaces: bare `gitlab.com` repo URLs (including nested subgroups) now clone like `github.com` URLs, and clone auth-failure hints name your actual git host
- Fable 5 is offered as an advisor in `/advisor` again for organizations with Fable access, with usage-credits consent set up through `/model fable`

### Changed
- `SendMessage` now delivers to a bare name that exactly matches one live session, instead of asking to confirm with a ref first
- Interactive sessions on one machine now keep unique names: starting or renaming a session to a name another live session already uses gives it a `name-word-word` variant and tells you
- Settings: `additionalMarketplaces` and `allowedMarketplaces` are now accepted as friendlier aliases for `extraKnownMarketplaces` and `strictKnownMarketplaces`
- `/code-review` at high, xhigh, and max effort now runs in a background agent like the other levels
- Updated agent panel: completed subagents hide immediately with a `/tasks` footer hint, and the "↓ N more" overflow indicator moved left for visibility
- `/plugin install plugin@marketplace` now refreshes the marketplace first, so newly published plugins install without a manual marketplace update
- Improved fullscreen streaming, managed settings approval dialog wording, Remote Control reconnect reliability (~30 min after a network blip)
- `/feedback` and `/bug` now open immediately when invoked while Claude is responding
- Removed the startup tip suggesting custom subagents and the matching `/powerup` nudge

### Fixed
- GitLab token family secret redaction (`glrt-`, `gloas-`, etc.) and hardened `glab` CLI config store protection
- Enterprise/gateway-only fixes: `desktop:` overlay schema validation, `blockedMarketplaces` url-typed entries, malformed `managed.policies`/`email_domain` values failing at boot
- Security/permission-bypass fixes: PowerShell `$PSDefaultParameterValues` overwrite, Windows Git Bash Cygwin-style symlinks, nested git repo trust inheritance, Bash input redirections (`< file`) now permission-checked
- MCP connections no longer hang the full 30s connect timeout on a malformed protocol-version reply
- Multiple Remote Control reliability fixes (bridge session credential isolation, reattach-not-duplicate, idle reachability, history restore after worker restart, replacement session on deleted claude.ai session, terminal state messaging)
- Cloud gateway `/login` silent exit, voice mode stuck on "listening…", mTLS client cert rotation requiring restart, malformed AWS/Vertex region fallback, stream idle timeout recovery on Bedrock/Vertex/gateway
- UI/rendering fixes: content-sized overlay truncation width, garbled mid-emoji preview cutoff, startup race unregistering plugin marketplace, `/update`/`/tui` restart refusal, usage-limit guidance suggesting unavailable slash commands, `--advisor fable` consent message wording
- Pasted/clipboard images read without blocking the event loop
- Cowork sessions no longer inline external @-imports from user-scope memory files
- Hardened cross-session messaging socket directory and Linux filesystem sandbox; `sandbox.ripgrep` now honored only from user/managed/`--settings` settings
