# 2026-11-04 — Claude Code v2.1.318

## Claude Code v2.1.318 (new since v2.1.317)

### Added
- Added a record of your answer when Claude Code asks to turn on the mods it writes in a session → **Affects:** No playbook impact (narrow mods-authoring UI detail, not a documented workflow step)
- Added `assume_role` on `mantle` upstreams of the Claude apps gateway, for a role in another AWS account and for per-developer AWS cost attribution → **Affects:** No playbook impact (enterprise gateway admin feature, consistent with past gateway-admin items)
- Added an `effort` option to a mod's `$.model.fork`, so a quick side job can run at `low` whatever effort the session uses → **Affects:** No playbook impact (mods authoring API detail at a level of granularity the playbook doesn't track)
- Added the date a stored claude.ai sign-in ends to `claude auth status` (`loginExpiresAt`) and to `claude -p` JSON results (`credential_expires_at`) → **Affects:** No playbook impact (auth CLI output field, not a documented behavior)
- Added a one-line stderr warning to `claude -p` text output, starting 10 days before a stored claude.ai sign-in ends → **Affects:** No playbook impact (narrow CLI warning)

### Changed
- Changed `deniedMcpServers` URL entries to also block Anthropic-provided servers whose upstream URL matches, and connectors in cloud sessions and on self-hosted runners, where the session is given the connector's own URL; otherwise deny a connector by name → **Affects:** Practices page (`managedMcpServers`/`deniedMcpServers` bullet)
- Changed background subagents to move a shell command to the background after 3 minutes on all providers, so the prompt cache doesn't expire while it runs → **Affects:** Practices page (Prompt Caching & KV Cache TTL configuration table)
- Changed `/claude-api managed-agents-onboard` to give a new agent's built-in tools, and a quickstart template's MCP tools, the `auto` permission policy ("Judge risky actions") by default, matching the Claude Console → **Affects:** Practices page (`/claude-api managed-agents-onboard` cheat-sheet row)
- Changed subagents to stop instead of switching models when "Switch models when a message is flagged" is set to "Ask each time" → **Affects:** No playbook impact (the underlying "switch models when a message is flagged" moderation feature isn't documented in the playbook, so there's no existing row to extend)
- Changed subagent progress summaries on Bedrock, Vertex, Foundry, or with telemetry off: on a cold prompt cache, one can now wait up to 5 minutes for the subagent's pending response → **Affects:** No playbook impact (internal timing tolerance, not a user-facing configuration)
- Changed what a mod attaches at `prompt.submit` to stay in the user's turn rather than go out as a system message → **Affects:** No playbook impact (mods internals, below the playbook's documentation granularity for the mods system)
- Changed Claude Code to no longer install or update the IDE extension when started in an IDE terminal; use `/ide` from an outside terminal or your editor's extensions view → **Affects:** No playbook impact (narrow IDE-extension install behavior)
- Changed the `/permissions` rule details, built-in rules and delete confirmation views to use the standard dialog → **Affects:** No playbook impact (UI dialog consistency change)

### Removed
- Removed the 2.1.288 fix that kept the model's earlier thinking when resuming a conversation started on 2.1.286 or earlier; that thinking can now be dropped → **Affects:** No playbook impact (this fix was never documented in the playbook, so there's nothing to amend)

### Fixed / Improved
- Fixed workflows re-running finished agents when resumed after a usage limit → **Affects:** No playbook impact (bug fix only; the playbook doesn't document the Workflow tool's resume-caching mechanics at this level of detail)
- [Cloud sessions] Added a No repository option; added the usual Chrome names (`google-chrome`, `CHROME_PATH`) so non-Playwright tools can find the built-in Chromium → **Affects:** No playbook impact (the playbook has no dedicated cloud-session-environment-setup section to anchor these to; noting for a future pass if one is added)
- Many shell, auth, cloud-session, gateway, self-hosted-runner, Remote Control, VS Code, and Claude Tag fixes/improvements → **Affects:** No playbook impact
