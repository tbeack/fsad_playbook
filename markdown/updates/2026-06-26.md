# 2026-06-26 — Claude Code v2.1.193

## New Features
- Added `autoMode.classifyAllShell` setting to route all Bash/PowerShell commands through the auto-mode classifier instead of only arbitrary-code-execution patterns → **Affects:** Config Cascade (Notable settings.json Keys callout)
- Added `claude_code.assistant_response` OpenTelemetry log event containing the model's response text. Redacted unless `OTEL_LOG_ASSISTANT_RESPONSES=1`; follows `OTEL_LOG_USER_PROMPTS` when unset → **Affects:** Monitoring (Events & Logs table + Opt-in Detail Levels callout)
- Added live file path autocomplete to bash mode (`!`) → **Affects:** No playbook impact (UX enhancement, no config/command)
- Added a startup notice when MCP servers need authentication, pointing at `/mcp` → **Affects:** No playbook impact (UX enhancement, no config/command)
- Added automatic memory-pressure reaping for idle background shell commands (disable with `CLAUDE_CODE_DISABLE_BG_SHELL_PRESSURE_REAP=1`) → **Affects:** Subprocess Sandboxing (hardening env vars table)

## Changed
- Added auto-mode denial reasons to the transcript, the denial toast, and `/permissions` recent denials → **Affects:** No playbook impact (UI improvement)
- Improved background agents: launch result no longer instructs Claude to "end your response" → **Affects:** No playbook impact (internal behavior)
- Improved MCP `headersHelper` auth: re-runs and reconnects automatically when a tool call returns 401/403 → **Affects:** Monitoring (Enterprise Configuration) and Notable settings.json Keys callout
- Improved plugin auto-rename: marketplace `renames` maps are now followed automatically, updating settings to the new name → **Affects:** Power Usage (Plugins collapsible)
- Improved `/add-dir` message when the directory is already a working directory → **Affects:** No playbook impact (UX improvement)
