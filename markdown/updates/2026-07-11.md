# 2026-07-11 — Claude Code v2.1.207

## Summary

Claude Code v2.1.207 released 2026-07-11. Codex rust-v0.144.1 unchanged.

## New Features
- Auto mode is now available without `CLAUDE_CODE_ENABLE_AUTO_MODE` opt-in on Bedrock, Vertex AI, and Foundry; disable via `disableAutoMode` in settings → **Affects:** Power Usage / Config Cascade / Notable settings.json Keys

## Changed
- Changed Bedrock, Vertex, and Claude Platform on AWS to default to Claude Opus 4.8 → **Affects:** Model & Effort table
- Changed auto mode to no longer read `autoMode` from `.claude/settings.local.json` (repo-resident); use `~/.claude/settings.json` instead → **Affects:** Notable settings.json Keys callout
- Plugin hooks/monitors/MCP headersHelper: `${user_config.*}` in shell-form commands is now rejected (shell-injection fix); use exec form (`args` array) or `$CLAUDE_PLUGIN_OPTION_<KEY>` → **Affects:** Hooks section exec form note
- Plugin option values (`pluginConfigs`) are no longer read from project-level `.claude/settings.json`; only user, `--settings`, and managed settings are honored → **Affects:** No playbook impact (pluginConfigs not documented)

## Fixed
- Fixed terminal freezing and keystroke lag while streaming responses with very long lists/tables/code blocks → **Affects:** No playbook impact
- Fixed auto-updater overwriting custom launcher at `~/.local/bin/claude`; `/doctor` now reports externally managed launcher → **Affects:** No playbook impact (/doctor already documented)
- Fixed `extensions.worktreeConfig` left in `.git/config` after last worktree removed → **Affects:** No playbook impact
- Fixed malformed bracket patterns in rules globs, skill paths, `.ignore`, and `.worktreeinclude` → **Affects:** No playbook impact
- Fixed crash loop in agent teams with malformed teammate mailbox message → **Affects:** No playbook impact
- Fixed Remote Control sessions not showing background agent progress on mobile/web → **Affects:** No playbook impact
- Fixed Bedrock repeatedly requesting fresh AWS SSO credentials → **Affects:** No playbook impact
- Fixed Deep research labeling every Fetch-phase agent "unknown" → **Affects:** No playbook impact
