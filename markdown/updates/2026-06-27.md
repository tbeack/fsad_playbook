# 2026-06-27 — Claude Code v2.1.195

## New Features
- Added `CLAUDE_CODE_DISABLE_MOUSE_CLICKS` env var to disable mouse click/drag/hover in fullscreen mode while keeping wheel scroll → **Affects:** Subprocess Sandboxing hardening env vars table

## Fixed
- Fixed hook matchers with hyphenated identifiers (e.g. `code-reviewer`, `mcp__brave-search`) accidentally substring-matching — they now exact-match. Use `mcp__brave-search__.*` to match all tools from a hyphenated MCP server → **Affects:** Hooks Deep Dive — Configuration — Matcher patterns table
- Fixed voice dictation on macOS capturing silence in long-running sessions after the default input device changes → **Affects:** No playbook impact
- Fixed voice dictation auto-submit never firing for languages written without spaces (Japanese, Chinese, Thai) → **Affects:** No playbook impact
- Fixed external plugins enabled only by project `.claude/settings.json` not requiring explicit install consent on every loader path → **Affects:** No playbook impact
- Fixed `/plugin` Enable/Disable not working when a plugin's `plugin.json` `name` differs from its marketplace entry name → **Affects:** No playbook impact
- Fixed background jobs disappearing from `claude agents` or losing data when written by a newer Claude Code version → **Affects:** No playbook impact
- Fixed reopening a crashed background task showing a blank screen for up to 5 seconds instead of its restart → **Affects:** No playbook impact
- Fixed background agent daemons running unreachable when the control socket fails to start, blocking restarts → **Affects:** No playbook impact

## Improved
- Improved voice mode on Linux: now distinguishes "no microphone" from "SoX not installed" when SoX is present but no audio capture device exists → **Affects:** No playbook impact
- Improved `claude agents` completed list to fill available vertical space; on short terminals the header compacts so live sessions stay visible → **Affects:** No playbook impact
- Improved Remote session startup with a provisioning checklist while the container starts → **Affects:** No playbook impact
