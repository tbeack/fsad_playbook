# CBP-230 — Deeplinks to playbook content

## Summary

Add scroll-spy URL updates so the browser's address bar always reflects the user's current reading position. Nav sub-items and sub-sub-items already have correct `href` attributes and the router already handles all 3 hash levels on initial load — the only missing piece is calling `history.replaceState` from the `sectionObserver` as sections scroll into view. A side-fix is also needed: `codex-hooks` is absent from `sectionToPageMap`, causing its nav link to fall back to the FSAD page.

## Assessment

The playbook already has a complete deeplink infrastructure:

- All nav items carry `href` attributes with the correct hash format:
  - Sub-items: `href="#fsad/overview"`, `href="#practices/hooks-deep-dive"`
  - Sub-sub-items (leaf): `href="#practices/hooks-deep-dive/lifecycle"`
- `handleRoute()` already parses all three levels (`#page`, `#page/section`, `#practices/section/leaf`) on `hashchange` and initial load.
- `openAndScrollToLeaf()` handles the 3rd-level leaf format correctly.

**What is broken / missing:**

1. **URL never updates on scroll.** `sectionObserver` (line 14142) updates nav highlights when sections scroll into view but never calls `history.replaceState`. Result: URL stays at the page or topic level (`#practices/skills-hooks`) while the user reads a specific section — the URL bar is useless for sharing.

2. **`codex-hooks` missing from `sectionToPageMap` (line 13552).** `scrollToSection('codex-hooks')` falls back to `targetPage = 'fsad'`, navigating to the wrong page.

**Location:** `fsad-playbook.html` — `sectionObserver` callback (~line 14142), `sectionToPageMap` (~line 13543)

### Step 2 — Add `replaceState` to `sectionObserver` callback (line 14142)

Inside the `sectionObserver` callback, after updating the nav highlights, add URL updates:

**For collapsible (leaf) elements** (the `if (isLeaf)` branch):
```js
// After updating .nav-leaf-item active state:
const leafItem = document.querySelector(`.nav-leaf-item[data-leaf="${id}"]`);
if (leafItem) {
  const leafHref = leafItem.getAttribute('href');
  if (leafHref && window.location.hash !== leafHref) {
    history.replaceState(null, '', leafHref);
  }
}
```

**For section elements** (after the `.nav-sub-item` active update block):
```js
const page = sectionToPageMap[id];
if (page) {
  const newHash = '#' + (page === 'practices' ? `practices/${id}` : `${page}/${id}`);
  if (window.location.hash !== newHash) {
    history.replaceState(null, '', newHash);
  }
}
```

Both changes are inside the existing `if (!entry.isIntersecting) return;` guard, so they only fire on entry.
