# CBP-139 — Create `dist` directory with self-contained single-file bundle

## Summary
The playbook ships as `fsad-playbook.html` but has two runtime dependencies that prevent it from being fully self-contained: the Google Fonts CDN link and two playground HTML files referenced via `<object>` tags. This task creates a `dist/` build pipeline that produces `dist/fsad-playbook.html` — a single, fully offline-capable file with all resources inlined.

## Assessment
**External dependencies:**
- `fsad-playbook.html` line 7: `<link href="https://fonts.googleapis.com/css2?family=Inter...">` — requires internet
- `add-task-playground.html` (20K) — referenced at lines 3017, 3021, 3026 via `<object data="...">` and `<a href="...">`
- `commit-changes-playground.html` (22K) — referenced at lines 3159, 3163, 3168 via `<object data="...">` and `<a href="...">`

No other CDN references. All CSS, JavaScript, Mermaid, and Highlight.js are already inline.

CBP-043 added hide logic for missing playground files — the `<object>` embeds are already wrapped with detection logic, so inlining them as data URIs is the cleanest path.

**Location:**
- `fsad-playbook.html` — source file at project root
- `add-task-playground.html` — project root
- `commit-changes-playground.html` — project root
- `scripts/` — existing directory for build tooling

## Plan

### Phase 1 — Create build script

1. Create `scripts/build-dist.py` — a Python 3 script (no third-party deps) that:
   a. **Inline Google Fonts**: fetch `https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700;800&family=IBM+Plex+Mono:wght@400;500&family=Source+Serif+4:ital,opsz,wght@0,8..60,400;0,8..60,600;1,8..60,400&display=swap` with a browser `User-Agent` header (required by Google Fonts to return WOFF2 CSS), parse the returned CSS to find all `src: url(...)` WOFF2 references, download each font file, base64-encode it, substitute `data:font/woff2;base64,...` into the CSS, then replace the `<link>` tag in the HTML with a `<style>` block containing the processed CSS.
   b. **Inline playground files**: read `add-task-playground.html` and `commit-changes-playground.html`, base64-encode each, build `data:text/html;base64,<encoded>` URIs, replace every occurrence of the relative filename string (in `<object data="...">` and `<a href="...">`) with the data URI.
   c. **Ensure dist/ exists** and write the result to `dist/fsad-playbook.html`.

2. Make the script executable (`chmod +x scripts/build-dist.py`).

### Phase 2 — Run the build and verify

3. Run `python3 scripts/build-dist.py` from the project root.
4. Confirm `dist/fsad-playbook.html` is created.
5. Open `dist/fsad-playbook.html` in the browser — verify fonts render, both playground embeds load, and no network requests are made.

### Phase 3 — Update .gitignore and README

6. Check `.gitignore` — if `dist/` is not already excluded, add it (dist artifacts are generated, not committed).
7. Add a one-line "Build" section to `README.md` explaining how to regenerate the dist file.

All criteria verified 2026-05-13 before commit.
