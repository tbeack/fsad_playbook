# CBP-252 — Add `language` setting to Notable settings.json Keys callout (v2.1.176)

## Summary

Claude Code v2.1.176 added a `language` setting. When set, it pins the language used for session titles generated by Claude Code (previously they were always generated in the language of the conversation). This is a user/project-level settings key.

## Assessment

The Notable settings.json Keys callout (`<ul>` around line 8580 in `fsad-playbook.html`) lists notable settings keys with brief descriptions. The `language` setting does not appear there. It should be added as a new `<li>` before the closing `</ul>` tag (alongside `wheelScrollAccelerationEnabled` and `enforceAvailableModels` which were added in CBP-251/250).

## Plan

1. Read lines ~8585–8591 of `fsad-playbook.html` to confirm exact insertion point.
2. Add a new `<li>` after the `enforceAvailableModels` entry (the current last item) and before `</ul>`:
   ```html
   <li style="margin-bottom:0;"><code>language</code> — Pin the language Claude Code uses when auto-generating session titles. Without this setting, titles are generated in the language of the conversation. Accepts BCP 47 language tags (e.g. <code>en</code>, <code>ja</code>, <code>fr</code>). Configurable at user or project level (v2.1.176).</li>
   ```
   The current last item (`enforceAvailableModels`) has `margin-bottom:0` — we need to change it to `margin-bottom:0.4rem` and set the new item to `margin-bottom:0`.

## Acceptance Criteria

- `language` setting appears in the Notable settings.json Keys callout.
- Description explains pinning language for session titles.
- Version tag `(v2.1.176)` included.
- Existing `enforceAvailableModels` entry updated from `margin-bottom:0` to `margin-bottom:0.4rem`.
